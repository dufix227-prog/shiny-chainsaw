## Скачать и запустить на Steam Deck / Linux

[ZIP рабочей ветки](https://github.com/pavlodrab/solid-umbrella/archive/refs/heads/hoplite/mesambria-1d976b4b.zip) → распаковать **весь архив** → открыть терминал в распакованной папке:

```sh
bash game/start.sh
```

[game/start.sh](game/start.sh) найдёт или скачает проверенный Godot 4.7.2, подготовит текущие исходники и запустит игру. Без sudo и Proton; после первой подготовки работает офлайн. [Инструкция для Steam Deck](game/steam-deck/README.md), включая управление и добавление в Steam. Физический Deck ещё не проверен.

**Следующей модели:** [актуальный гайд продолжения](implementation-plan/handoff/plan.md). **Новая отдельная проба:** [еда в мире → E-подбор → B-инвентарь → использование](implementation-plan/3d-probe/inventory/plan.md). [Взаимодействия основной игры, P-телефон и перебинд](ideas/common/design/mechanics/interaction/plan.md) пока остаются планом.
