# Контекст разработки (всё внутри game/)

Для следующих Hoplite-моделей есть отдельная актуальная точка входа: [HOPLITE_CONTEXT.md](HOPLITE_CONTEXT.md).

**Визуальное ревью автора 09.09.2026 имеет приоритет над прежними формулировками готовности:** текущие мир, катсцена, размеры, мим/НПС, церковь, меню и диалоги не приняты как проработанные. Автор попросил пока не исправлять код, а записать план. Он создан в [ПЛАН-ДОРАБОТКИ-ПРОБЫ-2026-09-09.md](ПЛАН-ДОРАБОТКИ-ПРОБЫ-2026-09-09.md); правила качества — в [AGENTS.md](AGENTS.md). Новый код не начинать до выбора автором ближайшего блока и ответов на его вопросы.

Автор пишет код и локально, и через Hoplite; один объединённый технический контекст отвергнут. Предлагаемая схема общей базы и отдельных контекстов версий, а также подтверждённые требования к таблицам готовности, числам, dev-режиму, ассетам, заглушкам, режимам, масштабу и приоритетам ошибок записаны в [плане процесса](ПЛАН-ПРОЦЕССА-РАЗРАБОТКИ-2026-09-09.md). Детали синхронизации ждут ответов автора.

Решения первого блока доработки 09.09.2026: сброс — в паузе с подтверждением; скорость — циклом ×1/×2/×5/×10/×15/×20/×50 только в dev-режиме; основная камера — от третьего лица; ширину тропы выбрать по трём коротким пробам; на кусте случайно появляется 0–3 видимых ягоды одного из десяти реальных видов, каждая собирается рядом отдельным нажатием `E`, базово даёт +5 сытости, размер стака — 52, состояние сбора сохраняется. Технически клюква/брусника дают ещё +5 жажды, облепиха — ×1,1 скорости на 30 секунд с сочетанием с кофе/яблоком.

Рыбалка доступна во всех озёрах; обязательное озеро остаётся на 260 м, дополнительные разрешено расставить модели. Лес образует сплошную стену: у каждого дерева своя коллизия по визуальному размеру, единого невидимого барьера нет. Для окружения разрешены только внешние ассеты CC0 либо собственные варианты.

К дополнительным озёрам ведут боковые тропинки, открывающиеся на карте при приближении к их началу. Земля имеет естественные проходимые перепады высоты. Все кусты, включая ягодные, проходимы, но уменьшают скорость кота в два раза. Мелкие камни движение не блокируют; крупные блокируют коллизией по видимой форме и размеру.

Дополнительные озёра в прологе необязательные. После получения удочки на 260 м в них можно рыбачить только с берега. Кот может заходить в замедляющую мелкую воду, но не в глубокую.

Стартовая катсцена длится около минуты, крупный план таблички — три секунды. У дороги нет невидимого барьера, после катсцены кот может вернуться назад; столкновение запускает `С9-машина` «глупый суицидник»: полёт кота в небо, отдаление камеры, «Конец», титры и автовыход. Камера от третьего лица свободно вращается, в настройках доступны фиксация прямо за котом и первое лицо; все настройки сохраняются.

Обновлено 09.09.2026. Временный запрет изменять файлы вне `game/` снят автором. Общая точка входа снова находится в корневом [CONTEXT.md](../CONTEXT.md); локальная модель использует [LOCAL_CONTEXT.md](../LOCAL_CONTEXT.md), Hoplite — [HOPLITE_CONTEXT.md](HOPLITE_CONTEXT.md). Основная работа выполняется одной сессией; помощников не запускать без конкретной независимой проверки, которая действительно экономит время и не дублирует работу.

## Железные правила (читать до любой правки)

1. Править файлы по теме во всём репозитории разрешено с 09.09.2026. Не делать массовую несвязанную синхронизацию: игровой код остаётся в `game/`, канон — в `ideas/`, общие правила/контексты — в корне.
2. **Не писать и не расширять сюжет без автора:** никакие реплики, имена, биографии, события, концовки. Декорации и геометрия — можно; тексты сцен — только по явной просьбе автора.
3. Не ослаблять тесты ради зелёного цвета. Новое правило кода — новый тест.
4. GDScript: табы, Godot 4.7.2. Код по ответственности: игрок/нужды/маршрут/диалоги/сохранения/интерфейс раздельно; файл на 1000+ строк требует обоснования.
5. Не коммитить и не публиковать самостоятельно — коммитит основная сессия после проверки. Не запускать `start.sh` с окном: автор работает на этом Steam Deck, окно у него на экране не открывать. Только headless.
6. Числа прогонов не переписывать своими, пока сам их не повторил.
7. Основной журнал автора — `game/requests/user-request.md` (зеркало; объяснение внутри).

## Что это за проект

Прототип «котиков» на Godot 4.7.2: управляемый антропоморфный кот, **дорога 500 м (6120 ед. мира, скорость 3,4) — скелет К1 от 08.09.2026**; К2: после ввода имени кот проходит стартовую катсцену от улицы с движущимися машинами через каменную тропу, зажатую плотным лесом, к управляемому старту на 0 м; **К3 (08.09.2026): каркас диалогов** — окно-новелла снизу с портретом-пробой, 4 каноничных варианта («не знаю/промолчать/не знаю языка/сбежать»), крестовина+A, B — закрыть, время в диалоге идёт; НПС-каркас с телом и зоной разговора (E/A), данные реплик отдельно от кода; монетки канона — карман счётчика без экономики; тестовый НПС «Прохожий» у 12 м с репликой-заглушкой «…». Нужды (голод/выносливость, по умолчанию выключены), подбор еды в мире, окно инвентаря 5+5 слотов с рюкзачными страницами (тестовые рюкзаки «1 ур. / 10 ур. A / 10 ур. B»), перестановка предметов как в Minecraft (перенос в пустой слот + обмен занятых), выброс на землю и повторный подбор. Мир сегментный (чанки 32 ед.); метки сцен на картах — по факту встречи. Это лаборатория-проба, не полный пролог. Сюжет пролога начинается без дома: улица → лес → церковь → Стинт (100 м) → Братишкин (189 м) → возврат → рыбалка → дорога → фывфыв → кража клубнички.

## Как проверять (headless, без окна)

```sh
ENGINE=~/.cache/10000-metres-probe/godot-4.7.2-linux-x86_64/godot
# если движка нет: bash game/start.sh --setup-only (скачает официальный 4.7.2)
for suite in run rendering needs route500 menu location_forest location_church inventory inventory_proof probe_inventory prologue_start intro_sequence dialogue npc_church church_beggar mime_tutorial stint bratishkin_stream pig_minigame pig_follow vtuber_room stint_report super_pig moderator_ending fishing road_encounters; do
  $ENGINE --headless --path game/3d-probe --fixed-fps 60 --script tests/$suite.gd
done
# pacing (полные 500 м ×2) — отдельно, ускорение fixed-fps 30:
$ENGINE --headless --path game/3d-probe --fixed-fps 30 --script tests/pacing.gd
```

Последний полный зелёный прогон основной сессии: **632 проверки, 0 падений** (09.09.2026: 611 проверок быстрых сюитов + 21 pacing), а также 15 тестов лаунчера. Новые сюжетные сюиты, включая `road_encounters`, отдельно прошли при 30/60/120 FPS. Важно: физический контроллер Deck жив даже в headless — случайные нажатия автора открывают карту/инвентарь посреди прогона.
