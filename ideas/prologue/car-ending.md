# Концовка столкновения с машиной (С9-машина)

**Статус: подтверждено автором 09.09.2026.** Это отдельная ранняя концовка пролога. Стабильный производный ID — `С9-машина`; существующие `С1–С9` не перенумеровываются.

## Условие

После стартовой катсцены кот может свободно вернуться к оживлённой дороге. Невидимого барьера нет. Столкновение с движущейся машиной запускает эту концовку.

## Катсцена

1. После столкновения кот летит в небо.
2. Камера отдаляется.
3. Появляется надпись **«Конец»**.
4. Идут титры.
5. Игра автоматически закрывается.

Название концовки: **«глупый суицидник»**.
