# Бабушка и ферма — цель кражи

**Статус: набросок автора (06.09.2026); имена и образы — позже.**

## Что известно

- В прологе герой с компаньонами идут **воровать клубничку** (см. [квест](strawberry-heist.md)).
- **фывфыв** стоит **перед фермой бабушки** — подтверждено (06.09.2026): помогает ограбить бабушку и даёт гайды.
- Цель кражи — **только бабушка, без дедушки** (автор, 06.09.2026). Ранний вариант «дедушка-фермер» снят.
- **Она на самом деле добрая, хотя изначально кажется злой**: если не пытаться сбежать — **просто так кормит** (автор, 06.09.2026, вечер).
- Реакция на кражу **не влияет на основную игру** (автор, 06.09.2026, вечер).

## Реплики — канон (07.09.2026)

- Фейки: «Я вас вижу, выходите!» / «Выходи, ворюга, вижу твой хвост!» / «Кто там шуршит? Выходи по-хорошему!»
- Поимка: «Попался, голубчик! Ну, рассказывай.»
- Вслед бегущему: «Беги-бежи, ворюга жалкий!» / «Ишь, пятки сверкают!»
- Сдача (герой не убегает): «Сдаюсь... Только не бейте.» → «Да кто ж тебя бьёт, глупенький... Иди сюда, горе луковое.» → «Голодный же. Садись, сейчас покормлю.» → «Я... клубничку хотел.» → «Так бы сразу и сказал. На, ешь. Только в кустах больше не сиди — простудишься.»

## Внешность — канон (07.09.2026)

Бабушка-кошка: светло-серая шерсть, морда и лапы белые, слегка растрёпана. Платок в мелкий цветочек, передник с большим карманом для клубники. Очки на кончике носа; брови строгие домиком — из-за них «кажется злой». Глаза тёплые, усы в стороны. В лапах лейка или тяпка; ходит не спеша вперевалку. Сердится — стучит лейкой по грядке.
