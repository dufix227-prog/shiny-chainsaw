# Черновики карточек 15 случайных NPC — кандидаты

**Статус: кандидаты.** Черновики по явному запросу автора 19.09.2026. Ничего из этого не утверждено: имена, характеры, задания, награды и реплики автор просматривает пачкой и указывает, что исправить или заменить. Идёт пачкой, не по одному.

Правила, общие для всех карточек (уже подтверждены в интервью): пропуск не окончателен; провал лишает награды и не блокирует путь; после выполнения NPC остаётся, повторной награды нет; состояние сохраняется в сейве; неудачная кража у NPC — −10 репутации, помощь +2…+20 по таблице.

Типы заданий: [Д] доставь/принеси · [П] найди потерянное · [Е] дай еду/предмет · [У] простая услуга. Награды: еда (эффект), предмет (список позже), подсказка, только репутация.

## Карточки подробно

### NPC-01 · Мурчик

- Внешность: маленький серый котёнок, большие жёлтые глаза. Характер: робкий, всему удивляется.
- Задание [У]: заблудился у развилки, просит показать дорогу к ручью, где его ждёт мама.
- Шаги: подойти → побежать рядом до ручья → мама котёнка благодарит.
- Успех: +2 репутации, подсказка «мост впереди охраняет сердитый гусь, не подходи близко».
- Провал: уйти на середине — задания не завершается, можно вернуться.
- Пропуск: да. Реплики: «М-мама сказала ждать у ручья… а где ручей?»

### NPC-02 · Барсик-Бродяга

- Внешность: крупный полосатый кот с надорванным ухом. Характер: спокойный, чуть ворчливый.
- Задание [Е]: проголодался, просит поделиться едой.
- Шаги: поговорить → отдать любую еду из инвентаря.
- Успех: +5 репутации, предмет «жестяная миска» (вместимость — детали при реализации).
- Провал: нет еды — отказ не окончательный.
- Пропуск: да. Реплики: «Не делись — так не делись. Коты мы или кто».

### NPC-03 · Пушинка

- Внешность: белая кошка с пушистым хвостом. Характер: игривая, легко отвлекается.
- Задание [П]: потеряла любимый клубочек в кустах рядом с дорогой.
- Шаги: поговорить → найти клубочек (мерцает) → принести.
- Успех: +10 репутации (задание), награда-еда «молоко» (восстанавливает выносливость).
- Провал: кража клубочка вместо честного поиска — та же награда, но −10 репутации за кражу.
- Пропуск: да. Реплики: «Ты не видел мой клубочек? Он розовый и самый лучший».

### NPC-04 · Дымок

- Внешность: дымчато-серый кот, серьёзный. Характер: деловой, говорит коротко.
- Задание [Д]: отнести кусок коры старому пню дальше по дороге.
- Шаги: взять кору → донести до пня → положить → вернуться (или не возвращаться: задание закрывается у пня).
- Успех: +10 репутации, подсказка «у кота со свинками за забором есть что стащить, но он следит».
- Провал: выбросить кору — задание провалено.
- Пропуск: да. Реплики: «Кора для пня. Пень любит кору. Не спрашивай».

### NPC-05 · Рыжик

- Внешность: рыжий кот с хитрой мордой. Характер: ласковый выпрашиватель.
- Задание [У]: просто просит почесать за ухом.
- Шаги: подойти → нажать «почесать».
- Успех: +2 репутации, еда «сушёная рыбка» (лечение) — дарит в благодарность.
- Провал: нет.
- Пропуск: да. Реплики: «Чуть левее… ага… вот это рай».

### NPC-06 · Соня

- Внешность: упитанная серая кошка, всегда полусонная. Характер: медлительная, добрая.
- Задание [П]: снесло ветром одеяльце, найти в лопухах.
- Шаги: поговорить → найти одеяльце → принести.
- Успех: +10 репутации, предмет «мягкая подстилка» (спокойный сон — детали при реализации).
- Провал: нет (одеяльце всегда на месте).
- Пропуск: да. Реплики: «З-зимой пригодится… а может и летом… з-заберу потом».

### NPC-07 · Кузя

- Внешность: худой чёрный котёнок, энергичный. Характер: суетливый переговорщик.
- Задание [Д]: мышонок Пик заигрался у дороги, надо позвать его к маме-мыши в нору.
- Шаги: найти Пика → сказать про маму → проводить до норы.
- Успех: +10 репутации, еда «ягодка» (временный бонус к скорости) от мыши-мамы.
- Провал: распугать Пика — можно попробовать снова через время.
- Пропуск: да. Реплики: «Пик! Пик же опять у дороги! Ну кто так играет!»

### NPC-08 · Тучка

- Внешность: голубовато-серая кошка. Характер: наблюдательная сплетница.
- Задание [Е]: хочет молока, предлагает новость за еду.
- Шаги: поговорить → отдать молоко/еду.
- Успех: +5 репутации, подсказка «на стриме у громкого кота лежит папка — все ищут».
- Провал: нет.
- Пропуск: да. Реплики: «Слухи за слухи, молоко за молоко. Пойдёт?»

### NPC-09 · Царап

- Внешность: тощий кот с обломанным когтем. Характер: независимый, гордый.
- Задание [У]: не может дотянуться до зудящего места на коре, просит полаять на дерево «для солидности».
- Шаги: подойти → нажать «полаять».
- Успех: +2 репутации, без предметов («помощь и есть награда»).
- Провал: нет.
- Пропуск: да. Реплики: «Не смеяться. Просто гавкни на дерево. Оно поймёт».

### NPC-10 · Бублик

- Внешность: круглый рыже-белый кот. Характер: обиженный гурман.
- Задание [П]: вороной утащен его бублик, надо найти и вернуть (ворона делиться не хочет — она просто кладёт его в дупло).
- Шаги: поговорить → найти дупло → достать бублик → отдать.
- Успех: +10 репутации, еда «половина бублика» (лечение) — делится сам.
- Провал: съесть бублик самому — провал и −10 репутации (кража).
- Пропуск: да. Реплики: «Это НЕ просто бублик. Это МОЙ бублик».

### NPC-11 · Ириска

- Внешность: кремовая кошечка с бантиком. Характер: нежная романтик.
- Задание [Д]: передать цветочек бабочке на лугу дальше по дороге.
- Шаги: взять цветочек → донести до луга → отдать бабочке.
- Успех: +2 репутации, без предметов (бабочка садится на нос — сцена настроения).
- Провал: смять цветочек — Ириска даст ещё один, задание не проваливается.
- Пропуск: да. Реплики: «Она такая жёлтенькая… ей пойдёт».

### NPC-12 · Граф Мурзик

- Внешность: пушистый дымчатый кот с «усами дворецкого». Характер: важный, вежливый.
- Задание [У]: приглашает составить компанию на завтрак — графам скучно есть одному.
- Шаги: принять → посидеть рядом (короткая сцена).
- Успех: +5 репутации, еда «сливки» (восстанавливает выносливость).
- Провал: отказ не окончательный.
- Пропуск: да. Реплики: «Прошу. Завтрак подан. Разговор обязателен, еда — по желанию».

### NPC-13 · Живчик

- Внешность: маленький трёхцветный котёнок-непоседа. Характер: громкий, восторженный.
- Задание [Д]: ветер унёс воздушный шарик, догнать и вернуть.
- Шаги: поговорить → догнать шарик (небольшой забег) → принести.
- Успех: +10 репутации, предмет «шарик» (игрушка, декор).
- Провал: упустить шарик далеко — можно попытаться снова.
- Пропуск: да. Реплики: «Лови-лови-лови! Ой… уже улетел…»

### NPC-14 · Лапка

- Внешность: аккуратная бело-серая кошка с ошейником. Характер: собранная, знает толк.
- Задание [П]: потеряла ключик от будки в траве у столбов.
- Шаги: поговорить → найти ключик → отдать.
- Успех: +10 репутации, подсказка «на 260 м у воды сидит рыбак — там хорошо ловится, если умеешь ждать».
- Провал: нет.
- Пропуск: да. Реплики: «Ключик маленький, блестит. Если найдёшь — я щедрая».

### NPC-15 · Старый Полосатый

- Внешность: старый полосатый кот с седой мордой, лежит на камне. Характер: мудрый, неторопливый.
- Задание [У]: просит выслушать историю о том, как дорога была длиннее.
- Шаги: подойти → слушать (пара реплик) → короткий ответ.
- Успех: +2 репутации, без предметов; после истории даёт одну фразу-намёк про бабушкину клубнику.
- Провал: нет.
- Пропуск: да. Реплики: «Сядь. Не навсегда. На минуту».

## Открытое для автора

- Имена и характеры — кандидаты, менять можно пачкой или точечно.
- Наградные предметы (миска, подстилка, шарик) — появятся в списке предметов, когда утвердим карточки.
- Подсказки привязаны к сюжетным точкам: гусь на мосту, свинки, папка, рыбалка 260 м, бабушкина клубника.
- Распределение по дороге (кто где стоит) — отдельное решение после утверждения пачки.
