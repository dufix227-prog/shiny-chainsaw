# Наброски GLM — основная история

**Статус: предложение агента (GLM-5.3), 06.09.2026.** Автор попросил «100 нпс прописанных, 100 мини игр, 70 случайных событий» к основной истории (10 000 м). Формат по уточнению автора — сначала короткие наброски; понравившиеся пропишем подробнее. Лор автор подпишет сам позже.

Правила:

- Всё ниже — не канон. Никаких имён, возрастов и биографий: только роль и поведение, чтобы автор мог сам привязать лор.
- Идеи не связаны жёстко с метрами и сценами — это пул для отбора.
- Чужие папки других моделей (`deepsik/`, `muse-spark/`) не читались и не использовались — по прямому указанию автора.
- Кент с пивком на 9989 м, рыбо-робот/затопление и события ямы — уже есть у автора и в [архиве НПС](../hoplite-working/main-story-npcs-events.md); здесь их дубликатов нет.

Файлы:

- [npcs.md](npcs.md) — 100 НПС, по 10 на каждую 1000 м пути.
- [minigames.md](minigames.md) — 100 мини-игр, по 10 в категории.
- [random-events.md](random-events.md) — 70 случайных событий по типам.

Как отбирать: отметить понравившиеся номера → прописать выбранные подробнее → только после этого переносить в действующие планы.
