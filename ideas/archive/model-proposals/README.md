## Как пользоваться

1. Ищи действующее решение сначала в тематическом плане (`prologue/`, `mechanics/`, `lore/`, `endings/` и других), а не в архиве.
2. Архив показывает происхождение необработанных идей и сохраняет авторство модели.
3. Если автор выбирает идею, перенеси только выбранное правило в подходящий действующий план, отметив источник и статус. Сам архив не переписывай как канон.
4. Будущие внешние пакеты идей размещать по той же схеме: отдельная папка источника, дата, README с границами и ссылка из этого каталога.
