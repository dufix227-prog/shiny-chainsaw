# 200 плохих случайных событий, часть 1: ПС-001–050 — кражи, обман, торг (предложение агента, 07.09.2026. Не канон)

Формат: триггер → выбор → исход. Всё мягко, всё возвращается/чинимо. Без смертей, без жёстких потерь.

### ПС-001. Обнимашки-щипок
Триггер: незнакомец бросается обниматься. Выбор: обняться / отстраниться / проверить карманы после. Исход: -1–3 монетки; при проверке сразу — ворона роняет их обратно. Урок: смотреть на руки.

### ПС-002. Платок под ногами
Триггер: платок ровно на тропе. Выбор: поднять и отдать / пройти мимо / поднять, держа рюкзак спереди. Исход: в первых двух — шанс -еды из бокового; в третьем — ничего. Напарник в кустах уходит ни с чем.

### ПС-003. Подмена при обмене
Триггер: меняла торопит «быстрее-быстрее!». Выбор: согласиться не глядя / пересчитать при нём / отказаться. Исход: не глядя — -2 монетки; пересчёт — докладывает и ворчит; отказ — вздыхает.

### ПС-004. Севшая батарейка
Триггер: тип из-под полы шепчет «вечные!». Выбор: купить с рук / купить у стенда / идти без света. Исход: с рук — гаснет через 100 м, фонарщик рядом меняет; у стенда — светит честно.

### ПС-005. Карта «клад!»
Триггер: продают крест на карте. Выбор: купить за 5 / поторговаться до 2 / отказаться. Исход: крест ведёт в лужу, там записка «купи ещё!». Возврат половины при наезде.

### ПС-006. Рваный зонт в аренду
Триггер: не дают осмотреть зонт до оплаты. Выбор: взять не глядя / потребовать осмотр / уйти мокнуть. Исход: не глядя — потом «ты порвал, с тебя булка»; осмотр — отступает и даёт целый.

### ПС-007. Носильщик-беглец
Триггер: хватает рюкзак и кричит «догоняй!». Выбор: отдать и идти сзади / нести самому / бежать следом сразу. Исход: отстал — -1 еда (роется за углом); бежал следом — ничего не успевает.

### ПС-008. Фото-шантаж
Триггер: щёлкнули без спроса, показывают «ты зеваешь». Выбор: заплатить / сказать «удаляй» / попросить нормальное фото. Исход: заплатил — -монетка за стыд; «удаляй» — удаляет и дарит хорошее бесплатно.

### ПС-009. Порча на ботинке
Триггер: хватают за обувь «вижу сглаз!». Выбор: заплатить за снятие / завязать самому / уйти. Исход: заплатил — обычный шнурок за цену; сам — ничего не случается, дети смеются.

### ПС-010. Чудо-капля
Триггер: пузырёк мутный, «от всего!». Выбор: купить / спросить состав / отказаться. Исход: купил — вода из лужи, эффекта нет; лесной врач потом объясняет. Состав — «секрет!».

### ПС-011. Суп без цены
Триггер: «ешь-ешь, потом сочтёмся!». Выбор: спросить цену до / поесть и узнать / уйти. Исход: поел — топор в залог, выкуп едой; спросил — цена едой сразу, честно.

### ПС-012. Короткий путь в тупик
Триггер: «срезка за еду вперёд!». Выбор: дать вперёд / дать после / идти по меткам. Исход: вперёд — тупик + «давай ещё — выведу»; после — ведёт верно, боится кидка.

### ПС-013. Доплата на середине
Триггер: лодка на середине, гребец останавливается. Выбор: доплатить / спеть / грести самому. Исход: доплатил — -сухарь; спел — добреет и довозит; сам — дольше, но бесплатно.

### ПС-014. Пошлина за чужой мост
Триггер: сидит на свежем мосту «мой!». Выбор: заплатить / позвать строителей / обойти вброд. Исход: заплатил — -монетка в никуда; строители — прогоняют его.

### ПС-015. Пчёлы по команде
Триггер: машет палкой у ульев «мои!». Выбор: дать булку / пройти тихо мимо / позвать пасечника. Исход: дал — пчёлы его самого гонят; тихо — проход свободен.

### ПС-016. Бензин кончился (кот-такси)
Триггер: везёт 2 метра и встаёт. Выбор: заплатить ещё / слезть и идти / сесть к настоящему. Исход: ещё — -монетка за 2 метра; слез — смех; настоящий рядом везёт бесплатно.

### ПС-017. Место под крышей занято
Триггер: ливень, сарай занят одним. Выбор: платить за «подвинуться» / искать второй сарай / стоять под деревом. Исход: заплатил — -сухарь; второй сарай у дежурного — бесплатно и сухо.

### ПС-018. Верёвка арендная
Триггер: все верёвки заняты его тряпками. Выбор: платить / сушить в руках / идти ко второму костру. Исход: второй костёр — бесплатно; этот остаётся с мокрым.

### ПС-019. Сено занято
Триггер: лёг поперёк, «подвинусь за монетку». Выбор: платить / лечь рядом / искать место у сторожа. Исход: сторож показывает второе место; этот храпит один.

### ПС-020. Хромой-спринтер
Триггер: просит «последний день не ел». Выбор: дать кусок / дать два / дать мало. Исход: убегает вприпрыжку с любым; давать по желанию, не жалеть. Настоящий хромой (121) — не просит, идёт рядом.

### ПС-021. Твоя кружка в продаже
Триггер: на раскладке твоя вещь. Выбор: выкупить за полцены / потребовать бесплатно / уйти. Исход: настойчивость — отдаёт бесплатно, связан со щипачом.

### ПС-022. Мост сгорел (враньё)
Триггер: бегут навстречу «не ходи!». Выбор: поверить и в обход / проверить 50 м / спросить подробности. Исход: мост целый; врун ведёт к лодке брата. Проверка — врёт и убегает.

### ПС-023. Котёнок в кустах
Триггер: плач «помоги, застрял!». Выбор: пойти / позвать лесника / дать яблоко сразу. Исход: в кустах брат «проход платный»; лесник — разбегаются; котёнок их домашний.

### ПС-024. Дед без очереди
Триггер: лезет «мне обещали!». Выбор: пропустить / промолчать / указать на очередь. Исход: пропустил — делится сухарём от стыда; очередь — ставит в конец.

### ПС-025. Держи место (пятеро)
Триггер: «я за тобой, вот ещё мои». Выбор: держать / отказать / позвать очередь. Исход: держишь — +5 перед тобой; очередь шумит — уходит в конец.

### ПС-026. Куплю место
Триггер: предлагает 2 монетки за место. Выбор: продать / не продавать / сторговать 5. Исход: продал — -время в очереди, +монетки; не продал — стоит сам в конце.

### ПС-027. Бледный квас
Триггер: квас светлый «летний!». Выбор: купить / спросить почему светлый / дождаться настоящего. Исход: купил — вода; настоящий возвращается и доливает.

### ПС-028. Маленькая за большую
Триггер: ночная смена кладёт половину. Выбор: принять / попросить «как себе» / прийти днём. Исход: «как себе» — смущается и докладывает; днём — честно.

### ПС-029. Холодные «горячие»
Триггер: «жгутся!» при холодной печи. Выбор: купить / потрогать сначала / идти к утренней. Исход: чёрствая; утренняя меняет на свежую.

### ПС-030. Синее молоко
Триггер: молоко синее «от васильков!». Выбор: купить / понюхать / отказаться. Исход: вода; вечерний меняет; этот сбегает.

### ПС-031. Сеть поперёк ручья
Триггер: ручей перегорожен. Выбор: порыбачить рядом / пожаловаться леснику / порвать сеть. Исход: лесник снимает, рыба возвращается; рвать самому — браконьер орёт (не дерись).

### ПС-032. Ворона на голове
Триггер: села на голову, орёт. Выбор: терпеть / кыш + проверить рюкзак / угостить крошкой. Исход: терпишь — -блестяшка; кыш — роняет обратно.

### ПС-033. Гусь «ещё!»
Триггер: хватает хлеб, требует ещё. Выбор: дать ещё / обойти по краешку / свистнуть в свисток. Исход: свисток действует; краешек — проход; «ещё» бесконечно.

### ПС-034. Рекс самостоятельный
Триггер: рычит на мосту, хозяин «не держит». Выбор: дать колбасу / обойти вброд / позвать доброго пса. Исход: добрый уводит играть; вброд — мокро, но свободно.

### ПС-035. Дай карту глянуть
Триггер: окружают «чё там». Выбор: дать / не давать / дать и держать край. Исход: дал — «верну за сухарь»; держать край — не вырвут; лесник разгоняет взглядом.

### ПС-036. Дистанционный толчок
Триггер: падает «убили!». Выбор: дать сухарь / стоять на своём / позвать очередь. Исход: дал — добреет, делится семечками; очередь смеётся — встаёт сама.

### ПС-037. Друг щас придёт
Триггер: лежит на скамейке 3 часа. Выбор: ждать / сесть на край / идти ко второй. Исход: вторая от ремонтника — удобно; этот один.

### ПС-038. Само разбилось (фонарь)
Триггер: гаснет свет, рядом мальчишки с рогатками. Выбор: проводить за монетку / чинить с фонарщиком / идти в темноте. Исход: фонарщик ставит их чистить стёкла, свет возвращается.

### ПС-039. Мой огонь!
Триггер: занял костёр «я раздувал!». Выбор: платить дровами / развести второй с дежурным / греться стоя. Исход: второй — бесплатно; этот один.

### ПС-040. Сюда! Тут мост! (из тумана)
Триггер: крик без света. Выбор: пойти на голос / идти на свет маячника / переждать. Исход: на голос — лужа; на свет — верная тропа.

### ПС-041. Запись в сарай
Триггер: блокнот «мест нет!». Выбор: платить 2 / заглянуть внутрь / искать сторожа. Исход: внутри пусто; настоящий пускает всех.

### ПС-042. Пропуск в лес
Триггер: «лес по пропускам!». Выбор: купить / спросить лесника / пройти мимо. Исход: лесник рвёт пропуска, проход свободный.

### ПС-043. Такси в гору
Триггер: «дёшево, быстро!». Выбор: сесть / спросить куда / идти пешком. Исход: везёт кругом 300 м; пешком — 100 м бесплатно.

### ПС-044. Бинт ночью х5
Триггер: аптекарь «ночью — пять!». Выбор: купить / торговаться / ждать утра. Исход: торг — сдаётся до 1 «для красивых»; врач дешевле.

### ПС-045. Лихач с брызгами
Триггер: звон в последний момент. Выбор: отскочить в грязь / стоять / поймать и отругать. Исход: грязь (-скорость до стирки); прачка отстирывает.

### ПС-046. Тут не клюёт!
Триггер: уводит с клёва на «свой мостик». Выбор: уйти / остаться / проверить у деда. Исход: у него не клюёт вообще; у деда — клюёт.

### ПС-047. Шуршание ночью
Триггер: сосед молчит днём, шуршит ночью. Выбор: рюкзак под голову / спать чутко / попросить сторожа присмотреть. Исход: под головой — попытка сорвана; сторож ловит «верни!».

### ПС-048. Настоящая карта (дороже)
Триггер: «брат жулик, я честный!». Выбор: купить вдвое дороже / сравнить кресты / уйти. Исход: крест тот же, лужа та же; братья дерутся — уходи.

### ПС-049. Налог на шаги
Триггер: лента «МЭР», печать-картошка. Выбор: платить сухарь / спросить документы / посмеяться. Исход: никто не платит; полицейский подтверждает: мэра нет.

### ПС-050. Суп только своим
Триггер: чужой у котла «свои — сюда!». Выбор: ждать настоящего / спорить / уйти. Исход: настоящий возвращается с дровами, все получают суп.
