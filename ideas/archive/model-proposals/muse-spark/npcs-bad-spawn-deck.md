# Колода спавна плохих событий + топ-20 для первых 500 м (предложение агента, 07.09.2026. Не канон)

## Общие правила (чтобы не бесило)

- Максимум 1 плохой ивент на 150–200 м, кулдаун 90 сек после любого плохого.
- Никогда два воровства подряд. После кражи — следующее только пустышка/смех.
- Потеря всегда мелкая (1–3 монетки / 1 еда) и возвращается в радиусе 100 м (добрая пара рядом / догнать / проверить).
- В первые 500 м — только учебные, без реальных потерь (см. топ-20).
- Ночные — только ночью, дождевые — только в дождь, водяные — только у воды.
- Вес: часто 10, иногда 5, редко 2. Ролл: биом → 1 ивент по весу → проверка кулдауна.

## Топ-20 для первых 500 м (обучение, без потерь)

Привязка к first-500m.md. Правило: в 0–500 м вор НЕ забирает — только пытается, игрок учится кнопкам «осмотреть / спросить цену / проверить рюкзак».

| м | Событие | Чему учит | Как проходит |
|---|---|---|---|
| 40 | ПС-078 Шишка на голову | Подбирать | Шишка падает рядом, не бьёт. Поднял — еда-заготовка. Смех. |
| 90 | ПС-180 Карта летит (ветер) | Бег/подбор | Карта отлетает на 5 м в траву. Догнал — вернул. Потерь нет. |
| 140 | ПС-010 Чудо-капля (у церкви) | Спрашивать состав | Священник рядом: «это вода». Учит кнопке «состав». Покупки нет. |
| 180 | ПС-008 Фото-шантаж лайт | Говорить «нет» | Фотограф: «удаляй?» — выбор «удаляй» — дарит хорошее фото. Денег не просит в туториале. |
| 220 | ПС-076 Камешек | Остановка/инвентарь | Колет — учит кнопке «привал/вытряхнуть». 20 сек. |
| 250 | ПС-025 Держи место (двое, не пятеро) | Очередь | Просят подержать для одного. Очередь из 2. Без стресса. |
| 280 | ПС-003 Подмена лайт | Пересчитать | Меняла торопит, но сумма мелкая (1). Кнопка «пересчитать» подсвечена. Докладывает. |
| 310 | ПС-006 Зонт лайт (у привала) | Осмотреть ДО | Зонт дают осмотреть, дырка видна. Выбор «осмотреть» — хвалят. Аренды нет, только урок. |
| 340 | ПС-032 Ворона на голове лайт | Проверить рюкзак | Садится, шумит, ничего не берёт в туториале. Кнопка «проверить» — пусто, ворона улетает. |
| 370 | ПС-101 Гусь-охранник (добрый) | Обход/хлеб | Стоит добрый гусь, шипит для порядка. Хлеб — пропускает. Учит механике гусей. |
| 400 | ПС-022 Мост сгорел (враньё) | Проверять самому | Врун кричит, мост виден через 30 м целый. Учит «проверь 50 м». |
| 420 | ПС-013 Доплата лайт | Петь/грести | Лодочник шутит про доплату, но везёт за договор. Песня — по желанию. Денег не берёт. |
| 440 | ПС-077 Ветка-хлестун | Пригнуться | Впереди идущий держит ветку. Учит «держать для следующего». |
| 460 | ПС-073 Шнурок | Чинить | Рвётся, рядом шнурочник даёт зелёный «к удаче». Бесплатно в туториале. |
| 475 | ПС-100 Мусор | Подбирать | Банки. Мусорщик: «сдай — монетка». Первая монетка честно. |
| 485 | ПС-040 Голос из тумана лайт | Идти на свет | Туманчика нет, маячник светит. Учит «иди на свет, не на голос». |
| 495 | ПС-155 Шуршание лайт | Рюкзак под голову | Шуршит ёж, не вор. Сторож: «это ёж, спи». Учит механике сна. |
| 500 | ПС-200-тизер Король | Потери возвращаются | Мусорщик показывает свалку вдали: «там Король всё хранит». Без встречи, только слух. |
| запас | ПС-026 Куплю место | Не продавать | Предлагает 1, очередь из 2. Отказ — стоит сам. |
| запас | ПС-030 Синее молоко лайт | Нюхать | Дают понюхать, не покупать. Вечерний меняет. Учит «понюхай». |
