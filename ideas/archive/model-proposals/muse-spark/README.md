Правила пула:

- Основной путь — 10 000 м; встреча короткая, затем герой продолжает путь.
- Разговор необязателен; уйти можно всегда, если не сказано иначе.
- Без имён/возрастов/мотивов как канона; номера НПС-001… — рабочие, не ID событий/концовок.
- Награды (еда, монетки, предметы) — предложения; баланс не утверждён.
- Ничего не переносится в [планы](../../../README.md) без явного ОК автора.
