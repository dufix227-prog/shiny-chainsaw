## UI-карточки: иконка + маркер-фраза + кнопка

Формат для движка: при триггере показывать карточку-подсказку 1.5 сек. Кнопка подсвечена.

### Торопит
- Иконка: ⏳ песочные часы + восклицание.
- Маркер-фразы: «бери пока есть!», «уже убегаю!», «только сейчас!».
- Кнопка: [Осмотреть] / [Пересчитать]. Герои: 303, 304, 307, 349, 344.
- Текст обучения: «Торопит? Осмотри».

### Нет цены
- Иконка: 🏷️ ценник с вопросом.
- Маркер: «потом сочтёмся!», «договор был до середины!».
- Кнопка: [Спросить цену ДО]. Герои: 306, 314, 318–320, 342–343.
- Правило: цены нет — не ешь / не садись.

### Двойник
- Иконка: 🎭 две маски.
- Маркер: стоит рядом с настоящим, но без стенда/бейджа; шляпа вместо сетки, печать-картошка, фуражка из бумаги.
- Кнопка: [Идти к спокойному]. Герои: 308, 317, 328–331, 365, 385, 391, 395–396.
- Подсказка: «У кого очередь — тот честный».

### Страх
- Иконка: 😱 + лужа.
- Маркер: «по уши!», «резать надо!», «беда!», «упадёт!».
- Кнопка: [Проверить у N рядом]. Герои: 311, 341, 352–355, 363, 367, 383, 386.
- N подсвечен стрелкой (спасатель, врач, маячник).

### Трогает / отвлекает
- Иконка: 🫂 + рука к карману.
- Маркер: обнимашки, «подними!», «дай глянуть!», ворона на голове, шуршание.
- Кнопка: [Рюкзак спереди] / [Проверить сразу]. Герои: 301, 302, 333, 336, 370, 390, 348.
- Пассивка: боковой застёгнут = иммунитет к 302/333.

### Я главный
- Иконка: 👑 из пробок / картошка-печать.
- Маркер: «мой мост!», «я мэр!», «я выездной!», «север — где я!».
- Кнопка: [Позвать настоящего]. Герои: 315, 342–343, 350–351, 354, 356.
- Настоящий стоит в 30 м, подсвечен.

### Зверь «ещё!»
- Иконка: 🪿 + «+1».
- Маркер: после первого куска требует второй; добрый уходит после одного.
- Кнопка: [Уйти пока ест] / [Свисток]. Герои: 334, 391, 396, 397–399. Исключение 394: [Спрятать сладкое] (делиться нельзя!).
- Правило: 1 кусок — норма, 2-й — вымогательство.

### Ночь / сон
- Иконка: 🌙 + рюкзак под головой.
- Маркер: шуршание, «доспать за монетку», храп.
- Кнопка: [Рюкзак под голову] / [Позвать сторожа]. Герои: 348, 373, 320, 342.
- Сторож всегда подсвечен ночью.

### Вода / брод
- Иконка: 💧 + палка-щуп.
- Маркер: «коротко!», «мелко!», камень шатается.
- Кнопка: [Ткнуть палкой] / [За тритоном] / [К бабке]. События: 052, 054, 057–058, 067, 088.
- Бабка/тритон подсвечены.

### Еда-ловушка
- Иконка: 🍏 + лупа.
- Маркер: блестит, «горячие!» при холодной печи, синее, бледное.
- Кнопка: [Понюхать] / [Показать травнице]. События: 119–134.
- Травница/отличница в 50 м.

Тексты кнопок короткие, глагол спереди. После 2 правильных проверок подряд — подсказки гаснут (игрок научился), остаются только иконки.
