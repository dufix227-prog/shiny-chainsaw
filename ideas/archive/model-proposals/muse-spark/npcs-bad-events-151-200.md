# 200 плохих случайных событий, часть 4: ПС-151–200 — ночь, соцподставы, техника (предложение агента, 07.09.2026. Не канон)

### ПС-151. Будильник в 3 ночи
Триггер: звон, темно. Выбор: прогнать / заплатить «доспать» / встать. Исход: прогнал — сон продолжается; сторож гонит его; добрый будит вовремя.

### ПС-152. Страшилка без конца
Триггер: дети плачут у костра. Выбор: вмешаться / позвать доброго сказочника / уйти. Исход: добрый чинит концовку; дети успокаиваются.

### ПС-153. Тихий час платный
Триггер: лёг поперёк сена. Выбор: платить / рядом / к сторожу. Исход: сторож показывает второе место; этот храпит один.

### ПС-154. Храп на весь сарай
Триггер: сосед храпит. Выбор: терпеть / пересесть / разбудить. Исход: пересел — тихо; разбудил — извиняется и тише; беруши из ваты у сушильщицы.

### ПС-155. Кто-то шуршит в рюкзаке
Триггер: ночью шуршит. Выбор: проверить с фонарём / крикнуть сторожа / притвориться спящим. Исход: сторож ловит «верни!»; под головой — сорвана попытка.

### ПС-156. Упал фонарь
Триггер: темно, звон. Выбор: поднять / купить батарейку / пристроиться к свету. Исход: путник с фонарём ведёт 200 м; батарейка у стенда честная.

### ПС-157. Свеча погасла
Триггер: сквозняк. Выбор: зажечь снова / к костру / спать. Исход: дежурный даёт огонь; ночь продолжается.

### ПС-158. Потерял тапок в темноте
Триггер: слетел в траву. Выбор: искать с фонарём / утром / босиком. Исход: утром находится в росе; фонарик на лбу у дворника помогает.

### ПС-159. Луна зашла за тучу
Триггер: стало темно. Выбор: ждать / идти медленно / зажечь светяшку. Исход: светяшка держит до утра; браслет-продавец честный.

### ПС-160. Сова ухает
Триггер: громко рядом. Выбор: испугаться / послушать / спросить про ночь. Исход: дневная сова сонно подсказывает про фонари; совёнок записывает.

### ПС-161. Очередь в суп (длинная)
Триггер: 10 котов впереди. Выбор: стоять / помочь раздавать / прийти позже. Исход: помог — добавка и благодарность; котёл почти не пустеет.

### ПС-162. Две миски в одни лапы
Триггер: дед берёт две. Выбор: промолчать / указать / пропустить. Исход: очередь ставит в конец; пропустил — делится сухарём.

### ПС-163. Место держат пятерым
Триггер: «мы вместе!». Выбор: держать / отказать / шуметь с очередью. Исход: шумишь — уходит в конец; держишь — +5 впереди.

### ПС-164. Кто-то влез без очереди
Триггер: протискивается. Выбор: сказать / промолчать / позвать дежурного. Исход: сказал — встаёт назад; дежурный знает расписание понаслышке, но порядок держит.

### ПС-165. Кричат «автобус!»
Триггер: слух «будет!». Выбор: ждать / идти пешком / спросить дежурного. Исход: автобуса нет; пешком — метры честные; взяточник врёт.

### ПС-166. Расталкивают у воды
Триггер: толпа у бочки. Выбор: ждать / набирать сбоку / помогать разливать. Исход: помог — первым набираешь; пожарный учит тушить.

### ПС-167. Заняли скамейку сумками
Триггер: сумки по краям. Выбор: попросить подвинуть / сесть на край / ко второй. Исход: вторая от ремонтника — крепкая; ворчун один.

### ПС-168. Громкая музыка рядом
Триггер: DJ орёт басами. Выбор: послушать / отойти / попросить тише. Исход: послушал — бодрость; отошёл — тихо; DJ ставит «для подъёма».

### ПС-169. Спор «лево-право»
Триггер: двое тянут. Выбор: послушать / поддержать / третьей тропой. Исход: поддержал — слух непроверенный; третьей — свой путь.

### ПС-170. Догонялки-мальчишки
Триггер: носятся, толкают. Выбор: посторониться / поиграть 1 минуту / строжить. Исход: поиграл — бодрость; посторонился — мимо.

### ПС-171. Рогатки по знакам
Триггер: звон по табличке. Выбор: сказать / пройти / позвать дворника. Исход: дворник метлой воспитывает; знаки чинит маляр.

### ПС-172. Рисуют на свежей краске
Триггер: мальчишки мажут забор. Выбор: сказать / помочь маляру / пройти. Исход: маляр даёт мазнуть честно; забор в полоску.

### ПС-173. Кто-то дёрнул за хвост (очередь)
Триггер: в толпе. Выбор: обернуться / промолчать / пошутить. Исход: шутка — смех очереди; виновник — котёнок, извиняется.

### ПС-174. Потерял очередь (отошёл)
Триггер: вернулся — не помнят. Выбор: встать в конец / напомнить / показать номерок. Исход: номерок от цапли спасает; встал в конец — честно.

### ПС-175. Перепутали заказ (квас/морс)
Триггер: дали не то. Выбор: поменять / выпить так / доплатить. Исход: тётка меняет без слов; «твоё — с брусникой!».

### ПС-176. Сдача не та
Триггер: не хватает 1. Выбор: пересчитать вслух / промолчать / пошутить. Исход: вслух — докладывают с извинениями; честный меняла вздыхает.

### ПС-177. Порвалась лямка
Триггер: треск на подъёме. Выбор: к швее / связать узлом / нести в лапах. Исход: швея шьёт + даёт шнурок; узел — до вечера.

### ПС-178. Развязался узел на сети
Триггер: сеть рыбака распустилась. Выбор: помочь / пройти / предупредить. Исход: помог — уха; рыбак делится местом.

### ПС-179. Сломался компостер контролёра
Триггер: «не щёлкает!». Выбор: подождать / нарисовать печать / идти так. Исход: нарисовал лапку сам — считается; контролёр смеётся.

### ПС-180. Потерялась карта (ветер)
Триггер: порыв — карта летит. Выбор: бежать / просить помочь / рисовать заново. Исход: ветер несёт в кусты рядом; клейщик чинит рваную; малец помогает ловить.

### ПС-181. Промокла карта
Триггер: дождь, карта плывёт. Выбор: сушить / перерисовать / купить самоделку. Исход: сушка у костра; самоделка «сам рисовал!» может врать шутки ради.

### ПС-182. Сел телефон-фонарь (если есть)
Триггер: моргнул и погас. Выбор: батарейка / костёр / к свету. Исход: чистильщик протирает — светлее; тётя-Фонарь ведёт 100 м.

### ПС-183. Разболталось колесо тележки
Триггер: скрип, восьмёрка. Выбор: чинить / бросить / тащить. Исход: дровокол чинит «бей в точку!»; конюх везёт рюкзак.

### ПС-184. Верёвка перетёрлась
Триггер: связка рассыпалась. Выбор: связать / попросить шнурок / нести в лапах. Исход: плетельщица учит «прутик под прутик»; шнурочник даёт зелёный к удаче.

### ПС-185. Черпак сломался (уха)
Триггер: треск. Выбор: есть вилкой / подождать ложкаря / помогать держать котёл. Исход: ложкарь дарит среднюю «для каши и ухи».

### ПС-186. Дрова сырые
Триггер: дым, не горит. Выбор: ждать / нести сухие / дуть. Исход: дровокол даёт сухие; дежурный раздувает; дым от комаров помогает.

### ПС-187. Спички отсырели
Триггер: чирк — мимо. Выбор: сушить / просить огонь / кремень. Исход: дежурный делится огнём; сухие — у сушильщика.

### ПС-188. Котёл закоптился
Триггер: чёрный. Выбор: чистить песком / есть так / просить новый. Исход: чистильщик трёт до блеска; каша вкуснее.

### ПС-189. Палатка протекает (шов)
Триггер: капает на нос. Выбор: переставить / зашить / спать под навесом. Исход: швея зашивает; навес сушильщика — сухо.

### ПС-190. Спальник мокрый
Триггер: лежал в луже. Выбор: сушить у костра / спать у сторожа / терпеть. Исход: сторож стучит колотушкой, присматривает; костёр сушит.

### ПС-191. Потерял ложку
Триггер: нет в кармане. Выбор: есть палочками / просить у ложкаря / искать. Исход: ложкарь дарит; вилкарь спорит; Крысиный король хранит потерянное.

### ПС-192. Кружка треснула
Триггер: течёт по пальцам. Выбор: пить быстро / чинить / купить у гончара. Исход: гончар даёт слепить свистульку, кружку меняет; треснувшая — для карандашей.

### ПС-193. Шляпа улетела
Триггер: порыв. Выбор: бежать / помочь поймать чужую / отпустить. Исход: в кустах рядом; путники помогают; новая — у торговца.

### ПС-194. Платок в грязи
Триггер: уронил в жижу. Выбор: постирать у прачки / выбросить / носить так. Исход: прачка стирает за песню; чистый — бодрее.

### ПС-195. Часы встали
Триггер: тикают — стоят. Выбор: к часовщику / сверить по солнцу / идти так. Исход: часовщик чинит, сверяет «день — 42 минуты»; солнце не врёт.

### ПС-196. Компас врёт (железо рядом)
Триггер: стрелка крутится. Выбор: отойти от моста / спросить компасника / идти по мху. Исход: компасник настраивает; мох — на север.

### ПС-197. Свисток не свистит (мокрый)
Триггер: шипит. Выбор: высушить / разобрать / купить новый. Исход: сушка у костра; продавец меняет; гусь боится сухого.

### ПС-198. Вертушка сломалась
Триггер: лопасть отлетела. Выбор: чинить / отпустить / купить. Исход: мальчишка меняет «синяя — самая ветреная»; сломанная — в коллекцию.

### ПС-199. Шарик лопнул
Триггер: хлопок. Выбор: расстроиться / отпустить остатки в небо / взять новый. Исход: продавец даёт второй «к удаче»; желание всё равно считается.

### ПС-200. Всё потерянное — у Короля (финал)
Триггер: чего-то не хватает после дня плохишей. Выбор: идти на свалку за мостом / махнуть лапой / спросить мусорщика. Исход: Король на троне из ящиков: «спой — отдам!». Поёшь — возвращает кружку/ложку/монетку. Мусорщик подтверждает: «он всё отдаёт за внимание». Шишка для короны — добреет навсегда. Урок всей серии: терять не страшно, возвращается смехом.
