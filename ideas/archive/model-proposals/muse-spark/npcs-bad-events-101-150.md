# 200 плохих случайных событий, часть 3: ПС-101–150 — звери, еда, погода (предложение агента, 07.09.2026. Не канон)

### ПС-101. Гусь держит тропу
Триггер: шипит поперёк у лужи. Выбор: обойти по краешку / дать хлеб / замахнуться. Исход: хлеб — жуёт и пропускает; замах — злится сильнее; краешек — проход.

### ПС-102. Гусь «ещё!»
Триггер: после хлеба требует добавки. Выбор: дать / уйти пока ест / свисток. Исход: ушёл пока ест — лучший; свисток — действует; «ещё» бесконечно.

### ПС-103. Ворона утащила пробку
Триггер: блестит — хватает. Выбор: обменять на еду / отобрать (ловкость) / отпустить. Исход: обмен — мелочь/еда; отобрать трудно, она ловкая.

### ПС-104. Белка-обстрел
Триггер: шишка в кепку. Выбор: дать орех / погрозить / уйти. Исход: орех — перемирие на 10 м; добрая белка ругает сестру.

### ПС-105. Пёс спит на мосту
Триггер: перекрыл доски. Выбор: прокрасться / разбудить и угостить / ждать. Исход: угостил — виляет и провожает; крался — мини-стелс.

### ПС-106. Пёс-задира
Триггер: рычит, хозяин «не держит». Выбор: обойти вброд / позвать доброго пса / дать колбасу. Исход: добрый уводит играть; колбаса — подобреет на минуту.

### ПС-107. Козёл на мостике
Триггер: стучит копытом. Выбор: лист капусты / вброд / ждать. Исход: лист — пропускает; ждать — долго и смешно; вброд — мокро.

### ПС-108. Козёл «вторая за выход»
Триггер: съел одну, требует вторую. Выбор: дать / обойти / позвать пастуха. Исход: пастух уводит; это вымогатель, а не добрый.

### ПС-109. Уж на обходе
Триггер: греется посреди. Выбор: перешагнуть / обойти / ткнуть. Исход: перешагнул — уползает на 10 см «проходи»; трогать не надо.

### ПС-110. Лягушка наврала про дождь
Триггер: квакает «к дождю». Выбор: поверить и готовиться / не верить / поймать-отпустить. Исход: ошибается через раз; зонт на всякий — не помешает.

### ПС-111. Пчела-разведчица в сумке
Триггер: кружит над сладким. Выбор: убрать поглубже / дать каплю / махать. Исход: убрал — улетела; капля — приведёт всех; махать бесполезно.

### ПС-112. Осиное гнездо рядом (не трогать!)
Триггер: гул сильный. Выбор: обойти тихо / бежать / кинуть шишку. Исход: тихо — мимо; шишка — погоня шутл. до воды; пасечник предупреждает.

### ПС-113. Комары у заката
Триггер: звон над водой. Выбор: дым / бежать до поляны / терпеть. Исход: дым деда — свободно; Бабайка-добрая пугает их.

### ПС-114. Муравейник разворошил (случайно)
Триггер: наступил на край. Выбор: отойти / извиниться крошкой в стороне / стоять. Исход: крошка в стороне — прорабы прощают; стоять — кусают шутл.

### ПС-115. Клещ в траве (осторожно!)
Триггер: высокая трава после поля. Выбор: осмотреться на привале / идти в штанах / к врачу. Исход: осмотр — снял сам; врач вынимает бесплатно и учит. Без страшилок.

### ПС-116. Крапива двойная
Триггер: с обеих сторон. Выбор: медленно боком / прыжком / назад. Исход: боком — сухо и цело; прыжок — жжение; лист лечит.

### ПС-117. Чертополох в носке
Триггер: колет через ткань. Выбор: вытряхнуть / терпеть / сменить. Исход: вытряхнул — легко; терпел — чешется.

### ПС-118. Репей на хвосте
Триггер: цепляется гроздью. Выбор: снять сразу / нести / попросить помочь. Исход: снял — чисто; нёс — смех очереди.

### ПС-119. Гриб-ложный (горький)
Триггер: красивый, но горький. Выбор: показать травнице / съесть / выбросить. Исход: травница: «только птицам!»; съел — несварение шутл. без смерти; повар ругает.

### ПС-120. Ягода незнакомая
Триггер: блестит, хочется. Выбор: показать травнице/отличнице / съесть / пройти. Исход: показали — «съедобно/только птицам»; съел — риск несварения; отличница учит.

### ПС-121. Пересол в супе
Триггер: суп пересолен. Выбор: запить водой / попросить другой / разбавить. Исход: волонтёр меняет; рвач продаёт воду; добрый даёт бесплатно.

### ПС-122. Холодная «горячая» булка
Триггер: «жгётся!» — холодная. Выбор: съесть / обменять у утренней / выбросить. Исход: утренняя меняет с сочувствием; чёрствая — сухарь сам.

### ПС-123. Скисшее молоко
Триггер: кислый запах. Выбор: вылить / вернуть / пить. Исход: вернуть — жадина сбегает, добрый меняет; пить — не надо, несварение шутл.

### ПС-124. Каша с комками
Триггер: комки как камни. Выбор: размешать / попросить другую / съесть. Исход: повар завтрака меняет с маслом; размешал — съедобно.

### ПС-125. Уха с костью
Триггер: кость поперёк. Выбор: выплюнуть / глотать / жаловаться. Исход: выплюнул — ешь дальше; повар-ухарь извиняется и доливает.

### ПС-126. Кукуруза сырая
Триггер: зёрна твёрдые. Выбор: дожевать / вернуть / доварить у костра. Исход: у костра доваривают бесплатно; кукурузник меняет.

### ПС-127. Орех пустой
Триггер: стук пустой. Выбор: выбросить / показать белке / коллекционировать. Исход: белка меняет на полный «самый большой»; пустые — в коллекцию шишек.

### ПС-128. Морковка вялая
Триггер: зайчиха дала вялую. Выбор: съесть / обменять / посадить шутл. Исход: съел — так себе; зайчиха меняет на хрустящую при возврате.

### ПС-129. Пирожок с «сюрпризом» (перец)
Триггер: внутри перец от перечника. Выбор: запить / доесть героически / поделиться. Исход: запил квасом — смех; перечник чихает «будь здоров!».

### ПС-130. Квас выдохся
Триггер: без газа, тёплый. Выбор: пить / вернуть / разбавить. Исход: квасник меняет на холодный из погреба; тёплый — «зубы не сводит».

### ПС-131. Чай остыл
Триггер: тётка налила давно. Выбор: пить холодным / попросить горячего / греть у костра. Исход: горячий — бодрит; холодный — тоже чай, но грустный.

### ПС-132. Мёд засахарился
Триггер: ложка стоит. Выбор: съесть так / растопить у костра / вернуть. Исход: у костра топят; дед-пасечник: «настоящий так и должен!».

### ПС-133. Сухарь-камень
Триггер: не грызётся. Выбор: размочить в чае / отдать голубям / грызть. Исход: в чае — отлично; сухарник меняет на свежие.

### ПС-134. Яблоко с червяком (домик)
Триггер: дырочка. Выбор: отдать ежу / съесть половину / выбросить. Исход: ёж рад; половина — съедобна; червяк — «белковый сюрприз» шутл.

### ПС-135. Ливень без зонта
Триггер: закапало, зонта нет. Выбор: аренда / покупка / мокнуть принципиально. Исход: аренда — вернуть на посту; мокнуть — хлюпанье без урона.

### ПС-136. Дождевик порвался
Триггер: треск на плече. Выбор: скотч / второй у раздатчика / терпеть. Исход: раздатчик меняет; скотч — до конца дождя.

### ПС-137. Ветер вывернул зонт
Триггер: порыв — купол наизнанку. Выбор: чинить у мастера / держать так / сложить. Исход: мастер чинит за 5 минут; зонт «дольше нас проживёт».

### ПС-138. Гроза близко
Триггер: вспышка + гул сразу. Выбор: в сарай / переждать / бежать. Исход: сарай — сухо и сено; бежать — мокро; под дерево нельзя.

### ПС-139. Туман-гигант
Триггер: не видно лап. Выбор: на свист / на свет / переждать. Исход: маячник выводит; туманник ведёт «ноги помнят».

### ПС-140. Роса-холод
Триггер: утро, ноги мокрые. Выбор: сухие носки / костёр / терпеть. Исход: продавец носков — скорость; костёр — тепло; терпел — хлюпает.

### ПС-141. Жара-плавление
Триггер: полдень, тень короткая. Выбор: тень зонта / морс / идти. Исход: продавец теней — морс иногда; мороженщик — охлаждение.

### ПС-142. Пыльная буря (мини)
Триггер: ветер с поля. Выбор: закрыть глаза / очки / переждать. Исход: очки — видно; переждал — прошло.

### ПС-143. Гололёд утром (тонкий)
Триггер: лужа с корочкой. Выбор: обойти / разбить / скользить. Исход: скользить — весело и мокро; обойти — сухо.

### ПС-144. Снег-пух (обманка)
Триггер: белое летит. Выбор: ловить / идти / показать другому. Исход: пух, не снег; смех полминуты.

### ПС-145. Радуга-спор (куда ведёт)
Триггер: двое спорят, где конец. Выбор: послушать / поддержать / пойти третьей. Исход: спор — игра; слух о коротком пути непроверенный.

### ПС-146. Закат-подстава (засиделся)
Триггер: красиво, не хочется уходить. Выбор: смотреть / идти / ночевать тут. Исход: смотрел — ночь ближе, планируй ночлег; ночёвка — по правилам сна.

### ПС-147. Ночь без света
Триггер: стемнело, фонаря нет. Выбор: к чужому свету / медленно / ночлег. Исход: с путником — безопасно; одному — шорохи без урона.

### ПС-148. Шорохи в кустах
Триггер: шуршит. Выбор: посветить / позвать / идти. Исход: ёж/мышка; ничего страшного; фонарь помогает.

### ПС-149. Карканье ночью
Триггер: вороны орут. Выбор: послушать переводчика / идти / переждать. Исход: перевод-«предсказание» шутл.; все понимают — игра.

### ПС-150. Дождь в ночь (холод)
Триггер: ночью закапало. Выбор: сарай / дождевик / костёр. Исход: сарай — сухо и сон; костёр под навесом — тепло и истории.
