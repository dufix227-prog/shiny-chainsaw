# 200 плохих случайных событий, часть 2: ПС-051–100 — дорога, вода, грязь (предложение агента, 07.09.2026. Не канон)

### ПС-051. Доска-ловушка
Триггер: доска через канаву трещит. Выбор: идти медленно / прыгнуть / обойти. Исход: медленно — держит; прыжок — трескается без падения (мост закроют, рядом обход). Подсказал «проверяй».

### ПС-052. Камень-вертушка
Триггер: камень у брода шатается. Выбор: наступать мягко / перепрыгнуть / обойти. Исход: мягко — держит; сильно — нога в воде. Тритон показывает верные.

### ПС-053. Грязь-обманка (сухая сверху)
Триггер: корка сухая, внутри жижа. Выбор: ткнуть палкой / идти смело / обойти. Исход: ткнул — видно глубину; смело — по щиколотку. Сапожник потом чистит.

### ПС-054. Лужа с двойным дном
Триггер: лужа-гигант, середина глубже. Выбор: вброд / по краешку / корыто-лодка. Исход: середина — по колено; краешек — сухо; корыто — сухо и весело.

### ПС-055. Мостик-попрыгун (доска пружинит)
Триггер: доска играет под ногой. Выбор: идти по краю / бежать / держать перила-канат. Исход: край + канат — сухо; бег — брызги. Канатчик держит.

### ПС-056. Перила оторвались
Триггер: перила шатаются. Выбор: не держаться / держаться слегка / сообщить кузнецу. Исход: кузнец чинит за «подержать»; держаться сильно — оторвёшь (потом стыдно, кузнец прощает).

### ПС-057. Ступенька в воду
Триггер: спуск к ручью скользкий. Выбор: боком / прыжком / за ветку. Исход: боком — сухо; прыжок — брызги; ветка — держит, но качается.

### ПС-058. Кочки-предатели
Триггер: кочка уходит из-под ноги. Выбор: медленно / быстро / по гати. Исход: медленно — сухо; быстро — мокро; гать — дольше, но сухо. Кикимора подмела гать.

### ПС-059. Бревно-каток
Триггер: бревно мокрое, крутится. Выбор: верхом / рядом вброд / подождать. Исход: верхом — весело и мокро при падении (без урона); вброд — предсказуемо мокро.

### ПС-060. Канава-невидимка (в траве)
Триггер: трава скрывает канаву. Выбор: идти по тропе строго / срезать / прощупать. Исход: срезка — нога в воде; тропа — сухо. Маляр отметил срезку крестом.

### ПС-061. Обход-замануха (длинный)
Триггер: табличка «обход сухо!» ведёт кругом 300 м. Выбор: пойти / проверить карту / спросить местных. Исход: обход честный, но длинный; местные показывают срезку 30 м за «пригни ветку».

### ПС-062. Срезка в крапиву
Триггер: тропка манит, впереди крапива. Выбор: ломиться / обойти / спросить травника. Исход: ломишься — жжение (лист от травницы лечит); обход — сухо.

### ПС-063. Забор без калитки
Триггер: забор поперёк, калитки нет. Выбор: перелезть с лесенчником / обойти / пролезть под. Исход: лесенчник держит — сухо; под — грязно; обход — долго.

### ПС-064. Ворота скрипят и клинят
Триггер: ворота заклинило наполовину. Выбор: протиснуться / позвать воротника / обойти. Исход: протиснулся — рюкзак застрял (помогают вытащить); воротник открывает торжественно.

### ПС-065. Калитка-хлопушка
Триггер: бьёт сзади по рюкзаку. Выбор: держать / проскочить / пропустить другого. Исход: держать — тихо; проскочил — хлопок и смех очереди.

### ПС-066. Плотина подняла воду
Триггер: бобры подняли ручей. Выбор: обойти по берегу / подождать / посмотреть. Исход: обход — сухо; ждать — бобры чинят, интересно. Ломать нельзя.

### ПС-067. Ручей после дождя — река
Триггер: знакомый ручей вдвое шире. Выбор: бревно / брод / ждать спада. Исход: бревно — быстро и страшно; брод — мокро; час — спад сам.

### ПС-068. Водопад-гул (манит)
Триггер: гул в стороне. Выбор: сходить / идти мимо / спросить. Исход: сходил — красиво, -время; мимо — путь продолжается; местные: «далеко, только гул».

### ПС-069. Туман съел метки
Триггер: метки не видно. Выбор: на звук / переждать / по памяти. Исход: на свист маячника — верно; по памяти — круг 5 минут; переждать — рассеется сам.

### ПС-070. Лужа-близнец (две, одна глубокая)
Триггер: две лужи рядом. Выбор: левую / правую / спросить воробья. Исход: воробей чирикает на мелкую; глубокая — по колено. Табличка «обход справа».

### ПС-071. Грязь на штанах (лихач)
Триггер: пронёсся и обрызгал. Выбор: отряхнуться / постирать у прачки / идти так. Исход: прачка стирает за песню (мокрые, но чистые); так — -скорость шутл.

### ПС-072. Подошва отлипла
Триггер: чавкает и отстаёт. Выбор: к обувщику / на скотч / босиком. Исход: обувщик — 3 стука и готово; скотч — до следующего поста.

### ПС-073. Шнурок порвался
Триггер: на подъёме — хлоп! Выбор: завязать узлом / взять у шнурочника / идти так. Исход: узлом — до вечера; шнурочник подбирает «к удаче».

### ПС-074. Штаны мокнут снизу
Триггер: трава высокая, роса. Выбор: подвернуть / терпеть / взять портного. Исход: портной подшивает «модно и сухо»; терпеть — мокро до колен.

### ПС-075. Носок сполз в ботинке
Триггер: комкает, натирает. Выбор: остановиться поправить / терпеть / сменить у сушильщицы. Исход: остановился — 1 минута, сухо; терпел — мозоль шутл. (лечится отдыхом).

### ПС-076. Камешек в ботинке
Триггер: колет каждый шаг. Выбор: вытряхнуть сразу / терпеть до привала / прыгать. Исход: сразу — 20 секунд и легко; терпел — хромота шутл. до скамейки.

### ПС-077. Ветка-хлестун
Триггер: впереди идущий отпустил ветку. Выбор: пригнуться / держать для следующего / отойти. Исход: пригнулся — мимо; держал — благодарность следующего; получил — шишка шутл.

### ПС-078. Шишка на голову
Триггер: стук сверху. Выбор: поднять на удачу / отбросить / показать коллекционеру. Исход: коллекционер меняет на мелочь; шишка — «самый большой» от белки.

### ПС-079. Жёлудь-дождь
Триггер: ветер, сыплются жёлуди. Выбор: укрыться / собирать / бежать. Исход: собрал — еда-заготовка (немного); укрылся — смех; стук — без урона.

### ПС-080. Пыль в глаза
Триггер: порыв на сухой тропе. Выбор: закрыть глаза / очки / промыть у ручья. Исход: промыл — чисто; терпел — слёзы 1 минуту (шутл.).

### ПС-081. Крапива у тропы
Триггер: задел рукой. Выбор: терпеть / лист подорожника / к травнику. Исход: лист — проходит; травник учит обходить.

### ПС-082. Комары тучей
Триггер: вечер у воды, звон. Выбор: дым деда / бежать / терпеть. Исход: дым — свободно; бег — до поляны; терпел — чешется (шутл.).

### ПС-083. Осы у варенья
Триггер: открыл сладкое — гул. Выбор: убрать поглубже / поделиться каплей / махать. Исход: убрал — улетели; махал — бесполезно; капля — приведут всех (не делать!).

### ПС-084. Муравьи в сумке
Триггер: сел на пенёк с крошками. Выбор: вытряхнуть / пересесть / поделиться в стороне. Исход: вытряхнул — чисто; поделился в стороне — муравьи-прорабы благодарят.

### ПС-085. Паук над тропой
Триггер: сеть поперёк лица. Выбор: обойти / снять палкой / пройти. Исход: прошёл — паутина на лице, смех; снял — паук злится, но цел.

### ПС-086. Кротовина под ногой
Триггер: свежий холм проваливается. Выбор: перепрыгнуть / обойти слева / топнуть. Исход: слева — сухо (мышка подсказала); провалился — по щиколотку, крот чихает.

### ПС-087. Корень-подножка
Триггер: торчит поперёк. Выбор: перешагнуть / споткнуться / отметить для других. Исход: споткнулся — коленка шутл.; отметил веткой — благодарность следующих.

### ПС-088. Скользкий мох
Триггер: камни в мохе у ручья. Выбор: медленно / прыжками / за тритона. Исход: за тритоном — сухо; прыжки — брызги.

### ПС-089. Песок в ботинках
Триггер: после брода песок скрипит. Выбор: вытряхнуть / терпеть / промыть. Исход: вытряхнул — легко; терпел — скрип на 10 минут, все слышат.

### ПС-090. Тина на камнях
Триггер: зелёные камни. Выбор: обойти / по ним / попросить бабку вести. Исход: бабка ведёт за палку — сухо; по ним — скользишь без падения.

### ПС-091. Отлив оставил ил
Триггер: после спада — ил. Выбор: по следам коз / напрямую / ждать. Исход: за козами — сухо (у них чутьё); напрямую — чавкает.

### ПС-092. Гроза застала на открытом
Триггер: гул близко. Выбор: к сараю / под дерево (нельзя!) / стоять. Исход: сарай — сухо; дежурный учит: под одинокое дерево нельзя, только навес/сарай.

### ПС-093. Град 30 секунд
Триггер: белая кромка тучи. Выбор: под козырёк / бежать / терпеть. Исход: терпел — шишки шутл.; козырёк — сухо. После — скользко.

### ПС-094. Ветер снёс указатель
Триггер: табличка валяется. Выбор: поднять и поставить / идти наугад / ждать маляра. Исход: поднял — +уважение тропы; маляр рисует заново с завитушкой.

### ПС-095. Размыло метку
Триггер: краска потекла. Выбор: идти правее (совет лесника) / ждать / спрашивать. Исход: правее — сухо; лесник обновляет метку.

### ПС-096. Повалило дерево
Триггер: свежее поперёк. Выбор: перелезть / обойти / убрать с прохожими. Исход: убрали — проход всем + благодарность; перелез — быстро, смолой пахнет.

### ПС-097. Яма с водой (прикрыта листом)
Триггер: лист подозрительно ровный. Выбор: ткнуть палкой / обойти / шагнуть. Исход: ткнул — яма видна; шагнул — нога мокрая, смех.

### ПС-098. Гудрон липнет (ремонт дороги)
Триггер: свежий кусок. Выбор: обойти / идти / снять у обувщика. Исход: липнет — -скорость до чистки; обход размечен.

### ПС-099. Свежая краска на перилах
Триггер: табличка «крашено!». Выбор: не трогать / потрогать / сесть. Исход: потрогал — лапа в краске (маляр смеётся, оттирает); табличку повесил маляр не зря.

### ПС-100. Чужой мусор под ногами
Триггер: банки поперёк. Выбор: перешагнуть / собрать / позвать мусорщика. Исход: собрал — монетка от чистюли; мусорщик знает, где теряют вещи (слух).
