# Идеи агента — отдельно от решений автора

По просьбе автора от 06.09.2026 агент складывает собственные идеи в отдельную папку, автор их оценивает и решает, что переносить в канон.

Записанные идеи:

- [prologue-npcs-events.md](prologue-npcs-events.md) — стартовый набор: НПС и события пролога, кнопочные мини-игры, заготовки НПС полной истории (06.09.2026, по запросу автора).
- [prologue-story-30min.md](prologue-story-30min.md) — сюжетное наполнение пролога под бюджет 30 минут: раскладка встреч и биты-связки, без новых НПС (07.09.2026, по запросу автора).
- [prologue-thin-spots.md](prologue-thin-spots.md) — 3 бита на пустые отрезки 0–100 м и после 189 м, существующим кастом (07.09.2026, по запросу автора).
- [fight-mechanics.md](fight-mechanics.md) — увороты, теллы, контрудар, бандит 15 ХП (07.09.2026, по запросу автора).
- [main-story-npcs-events.md](main-story-npcs-events.md) — большая подборка НПС, микроквестов и событий основной истории, включая затопление из-за рыбо-робота (06.09.2026, по запросу автора).
- Большой пакет из корня вынесен в [GLM-5.3-ideas/](../GLM-5.3-ideas/README.md): 100 НПС, 100 мини-игр, 70 событий (06.09.2026, по запросу автора).

Правила:

- Идеи агента не являются каноном и не переносятся в планы без явного подтверждения автора.
- Документы называются по теме (например, `minigames-fishing.md`) и связываются с существующими планами.
- В каждом документе помечено: предложение агента, дата, к какому плану относится.
