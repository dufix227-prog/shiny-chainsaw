# Концовки: завершение пути, а не каждый выбор

Источник — [ответы автора](../../requests/user-request.md). **Концовка завершает текущее прохождение и показывает итог жизни/пути героя.** Сдать предателя полиции, простить, изгнать или обойти яму — события: герой ещё может дойти до кошки. Прежний каталог смешивал эти категории; ниже они разделены.

В карточках отдельно обозначены авторская основа и предложенная постановка. Конкретная последовательность кадров — материал для утверждения, не уже согласованный полный сценарий. Романтические роли взрослые; откровенных сцен нет.

## Завершающие ветки

| ID | Итог прохождения | Где конкретные условия и последние сцены |
| --- | --- | --- |
| E01 | Герой не выбирается из ямы; путь оборван, предатель обманывает будущую жену | [Не дошёл](pit/plan.md); точная судьба героя открыта и отложена автором |
| E02 | Герой приходит к будущей жене и начинает жизнь на ферме | [Новый дом](home/plan.md); полиция/прощение/спутники меняют детали, не отменяют прибытие |
| E06 | Герой отказывается от пути к будущей жене и едет к другой кошке | [Автобусные финалы](bus/plan.md) |
| E07 | Герой не выжил; предатель добрался до будущей жены, но кошка по разговорам разоблачает самозванца | [Разоблачённый самозванец](exposed/plan.md); судьба самозванца открыта |
| E09 | На 6767 м выбирает союз с предателем; затем злодейский эпилог | [Союз](alliance/plan.md) |
| E10 / E11 | Тюрьма после мести: поимка в пути / признание партнёрше и её заявление | [Два варианта тюремного финала](crime/plan.md); общий итог, разные завершающие сцены |
| E12 | Добрался до фермы, скрыл убийство и прожил с этой тайной | [Жизнь с тайной](crime/plan.md) |
| E14 | Отказывается от нового дома и возвращается к прежней жизни | [Автобусные финалы](bus/plan.md) |
| E15 | После отказа от пути остаётся без дома и поддержки | [Автобусные финалы](bus/plan.md) |
| E16 | Осознанно выбирает свободную жизнь в путешествии | [Автобусные финалы](bus/plan.md) |

E10/E11 сохраняют прежние обозначения для ссылок, но не считаются двумя совершенно разными судьбами только из-за способа ареста. Число произведённых концовок не фиксируем до утверждения сцен. E07 подтверждена автором как отдельная концовка; в [предложениях](proposals/plan.md) остаются E13 (не выбраны условия шуточного острова) и кандидат «предатель добрался быстрее» (номер не назначен).

## Что убрано из счётчика концовок

| Прежнее обозначение | Правильная категория | Куда ведёт |
| --- | --- | --- |
| E03 «Предатель отвечает» | Сюжетное решение: передать доказательства полиции | [EV-RECKON](../lore/events/reckoning/plan.md) → продолжение пути → в том числе E02 |
| E05 «Прощение» | Решение и запрошенное [достижение](../../common/systems/achievements/plan.md) | Продолжение пути; E09 требует нового явного выбора, не выдаётся за само прощение |
| E08 «Ловушка не сработала» | Успешный обход события | [EV-PIT](../lore/events/pit/plan.md) → продолжение пути; достижение пока лишь предложение |
| E04 «Цена мести» | Название ветки, а не её конец | [Розыск](../lore/events/radio-search/plan.md) → E10/E11/E12 |

Номера не переиспользуем. Изгнание, передача билета, ответ в телефоне и способ спасения тоже не получают финальный ID сами по себе. Достижения открываются отдельно от главного итога и могут сочетаться с ним.

## Правила завершения и пересечений

- Финал записывается только в завершающей сцене, не при первом связанном выборе. До неё события могут менять направление истории.
- Один проход получает один главный итог и, при необходимости, вариант эпилога. Набор достижений при этом может быть любым допустимым.
- Сначала проверяется уже случившееся завершение: после E01/E09/ареста новый финал поверх него не запускается. Это не скрытый приоритет списка, а прекращение управления в достигнутом сюжетном узле.
- Полиция забрала предателя → он не возвращается свободным в союзной ветке. Предатель мёртв → E09 невозможен. Прощение само по себе не делает героя злодеем.
- Остаться в автобусе после обратного звонка → основной путь закончен; прыжок до окончательного подтверждения → временная травма и продолжение. География и пересечение автобусной ветки с розыском ещё требуют утверждения; нельзя считать розыск автоматически снятым.
- Профиль открытых финалов/достижений отделён от состояния прохождения. Любой уже созданный подходящий сейв можно загрузить даже после плохого финала: [правила](../../common/design/saves/plan.md). Хард ограничивает создание, а не выбор из грибных снимков.

## Проверка будущей реализации

Полиция → дорога → E02; прощение → дорога → E02; обход → дорога → E02; прощение + явный союз на 6767 м → E09; убийство → радио через 100 м → E10 либо прибытие → E11/E12. Проверить каждый автобусный исход и E01 отдельно. E07 проверять как отдельную концовку ветки подмены: игрок не делился историями → кошка распознаёт самозванца. Непроработанные кандидаты (E13, «предатель добрался быстрее») не становятся скрытым запасным исходом.
