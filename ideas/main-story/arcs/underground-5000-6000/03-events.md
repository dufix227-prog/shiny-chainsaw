# Подземные события ПЗ-С-01–30 (рабочая детализация каноничной арки; неподтверждённые детали — предложение агента)

Формат: триггер → выбор → исход. Всё мягко.

### ПЗ-С-01. Очнулся — темно
Триггер: открыл глаза, темно. Выбор: позвать / пошарить / лежать. Исход: светляк прилетает сам; мох мягкий; шишка шутл.

### ПЗ-С-02. Рюкзак пуст
Триггер: шарю — пусто. Выбор: кричать / искать / плакать-смеяться. Исход: крысёнок убегает с последним сухарём; мама-крыса кормит. Потеря зафиксирована (список для суда!).

### ПЗ-С-03. Фонарь разбит
Триггер: стекло треснуло. Выбор: чинить / банка-светляк / идти в темноте. Исход: чинильня чинит за работу; банка — временный свет.

### ПЗ-С-04. Первая работа
Триггер: Спора просит полить. Выбор: полить / отказаться / попросить сначала поесть. Исход: полил — миска похлёбки; мини-игра лейка 20 сек.

### ПЗ-С-05. Вагонетка
Триггер: просят толкнуть. Выбор: толкать / вдвоём / отказаться. Исход: толкнул — +еда, уважение крысят; вдвоём — быстрее и веселее.

### ПЗ-С-06. Вентилятор
Триггер: душно, крути! Выбор: крутить / меняться / отдыхать. Исход: покрутил — воздух свежее всем; смена — крысёнок угощает.

### ПЗ-С-07. Сортировка пробок
Триггер: куча пробок. Выбор: сортировать / сбежать / спросить зачем. Исход: отсортировал — мелочь (первые деньги внизу!); «для короны!».

### ПЗ-С-08. Доска потерь
Триггер: видишь свою кружку в списке. Выбор: заявить / промолчать / сорвать. Исход: заявил — Вторая Рука записывает «дело №102»; срывать нельзя.

### ПЗ-С-09. Номерок в очередь
Триггер: стражники требуют. Выбор: взять / потерять / подождать. Исход: взял — №102 (как падения!); потерял — дают новый, смеются.

### ПЗ-С-10. Следы-крошки
Триггер: крошки твоего сухаря ведут в штрек. Выбор: идти / взять крота / звать стражу. Исход: с кротом — безопасно; улика для суда.

### ПЗ-С-11. Шнурок-улика
Триггер: обрывок у норы Хвоста. Выбор: взять / оставить / показать Руке. Исход: показал — +доказательство; Рука кивает.

### ПЗ-С-12. Банка-улика
Триггер: пустая банка у Шёпота. Выбор: забрать / оставить / спросить. Исход: Шёпот краснеет — почти признание.

### ПЗ-С-13. Шорох-пугалка
Триггер: шуршит в темноте. Выбор: посветить / позвать / стоять. Исход: крысята играют в «страшного»; смех.

### ПЗ-С-14. Капает на нос
Триггер: кап-кап. Выбор: отойти / подставить кружку / терпеть. Исход: набрал воды; кружка вернулась кстати (если уже вернули часть).

### ПЗ-С-15. Скользкий мох
Триггер: ноги едут. Выбор: медленно / за верёвку / сесть. Исход: верёвки везде — держись; упал — мягко, смех.

### ПЗ-С-16. Тупик-завал
Триггер: ход завален. Выбор: разбирать / обойти / позвать. Исход: разобрали вдвоём с крысами — проход + благодарность.

### ПЗ-С-17. Свежая копка
Триггер: земля рыхлая, пахнет верхом. Выбор: копнуть / позвать червя / обойти. Исход: червь меряет «+2 шага! кто?!» — улика.

### ПЗ-С-18. Голод внизу
Триггер: живот урчит. Выбор: работать / просить / терпеть. Исход: работа = еда всегда; просить — мама даёт; терпеть не надо.

### ПЗ-С-19. Темнота давит
Триггер: долго без света. Выбор: к костру-бочке / обнять банку / петь. Исход: у костра тепло и истории; песня — светляки слетаются.

### ПЗ-С-20. Спор крысят
Триггер: дерутся за шнурок. Выбор: подарить / отобрать / рассудить. Исход: подарил временный бантик — восторг; на суде вернут.

### ПЗ-С-21. Торг со скупщиком
Триггер: твоя вещь на полке. Выбор: петь / работать / требовать. Исход: спел — отдал; до суда — часть вещей так возвращается.

### ПЗ-С-22. Летопись рассказывает
Триггер: села рядом. Выбор: слушать / спросить про небо / уйти. Исход: слушал — бафф спокойствия; «ты 102-й!».

### ПЗ-С-23. Проверка фонаря
Триггер: чинильня готова. Выбор: забрать / поблагодарить / доплатить. Исход: фонарь светит; доплата — мох в подарок.

### ПЗ-С-24. Мост из дверей
Триггер: скрипит. Выбор: медленно / бегом / за стражником. Исход: медленно — держит; сторож-мостовик (наш!) подсказывает.

### ПЗ-С-25. Ручей подземный
Триггер: течёт в темноте. Выбор: умыться / набрать / послушать. Исход: вода холодная, бодрит; лодочка-корыто рядом ждёт.

### ПЗ-С-26. Очередь к трону
Триггер: долго. Выбор: ждать / болтать / дремать. Исход: поболтал — слухи; номерок вызывают: «102-й!».

### ПЗ-С-27. Приём (5850)
Триггер: трон, Король. Выбор: просить расследовать / показать список / молчать. Исход: Король: «Скучно! Давай дело!» → Рука сдаёт троих → суд.

### ПЗ-С-28. Суд (мини-игра)
Триггер: трое стоят, книга открыта. Выбор: предъявить улики (крошки/шнурок/банка) / простить / требовать всё. Исход: предъявил 2+ — возврат; простил — всё равно возврат + уважение; воры ноют и отдают. См. механику.

### ПЗ-С-29. Возврат -50%
Триггер: куча вещей + опись. Выбор: пересчитать / обнять воров / спросить про налог. Исход: вещи все, монеты -50% (налог городка, Рука показывает запись). Обиды нет — чек выдан!

### ПЗ-С-30. Лифт наверх
Триггер: клеть, верёвки. Выбор: ехать / попрощаться / посмотреть вниз. Исход: 30 сек вверх, свет, птицы. Банка светляков в подарок. Выход ~5900.
