# Детализация: быт, запахи, звуки, распорядок (рабочая детализация каноничной арки; неподтверждённые детали — предложение агента)

## Запахи по зонам (для звука/текста, не для механики)
- Карман: сырая земля + мох (сладковатый) + твоя же пыль сверху.
- Грибная: туман-вода + тёплые грибы + свёкла-чернила из Книжного.
- Площадь: хлеб + корневой чай + тёплая пыль люка + пробковая пыль.
- Штреки: холод + железо + старые верёвки. Свежая копка пахнет верхом (трава!) — поэтому её находят по запаху.
- Зал: светляк-пыль (медовая) + дерево ящиков + лак пробок.
- Лифт: смола верёвок + ветер сверху (трава, вода!).

## Текстуры под лапами
- Мох — мягко, пружинит, тихо. По нему идут босиком крысята.
- Утоптанная земля — глухо, тепло.
- Доски-мостки — гулко, щекотно через лапы.
- Люк-площадь — холодный металл, звонкий. Крысята катают по нему пробки.
- Верёвки — шершавые, тёплые от лап. Их гладят на удачу.

## Распорядок Гулгорода (день внизу = капь сверху)
- Подъём — когда капает (утро верха). Все потягиваются, мох поливают.
- Работа — толкают/крутят/льют до второй капи.
- Тихий грибной час — шёпот, грибы спят, крысята учат узлы.
- Очередь — после чая. Суд/песни — вечером.
- Сон — под шорох. Сторожей нет — все друг друга слышат (стены тонкие, все свои).

## Еда подробно
- Похлёбка грибная: грибы + вода-капь + крошка сухаря для густоты. Едят из крышек. Добавка — за песню.
- Сухарь из подкладки: традиция! Каждый упавший прячет один. Мама находит и возвращает: «вот, завалялся!». Не облагается налогом!
- Чай корневой: корни + мох-щепотка + капля мёда (если есть). Пьют из пробок-стаканчиков (смешно, мало!).
- Капля свежая: подставляют кружки под капь. Самая вкусная — первая после дождя верха.

## Сленг (словарь для диалогов)
- светлый — упавший сверху (ты).
- шуршать — воровать по-мелкому (стыдно, так не говорят вслух).
- вписан — свой, записан в книгу.
- капь — дождь внизу (капает).
- гул — новости/шум сверху.
- пробка — деньги/уважение («пробочный!» = крутой).
- мох — свет/тепло/забота («мох тебе!» = «обнимаю!»).
- лапка — печать/договор («по лапкам!» = «договорились!»).

## Детские игры
- «Упавший»: один падает на мох с криком «а-а-а!», остальные ловят. Тренируют встречу!
- «Суд»: судят пробку за то, что укатилась. Приговор — вернуть!
- «Лифт»: тянут друг друга на верёвке вверх по горке. Визг!

## Законы и штрафы (смешные)
- Не вернул — моешь мох (он скользкий, все смеются).
- Шуршал — поёшь три песни подряд.
- Копал без спроса — засыпаешь обратно + угощаешь всех.
- Шумел в грибной час — учишь узлы с малышами (самое страшное! они строгие!).

## Одежда и вещи
- Фартуки из пакетов, каски-крышки, очки-проволока, шарфы-шнурки.
- Сумки из подкладок упавших (каждая с историей: «это 57-го!»).
- Корона чинится пробками. Шишка игрока — сбоку на честном слове и смоле.

## Страхи и утешения
- Боятся: тишины долгой (гул пропал — верх забыл?), завалов, темноты без светляков.
- Утешаются: песней, чаем, «мох тебе!», историей Летописи про небо.
- Игрок дарит главное утешение — песню сверху и рассказ про птиц (крысята просят «ещё про чик-чирик!»).

## Что видит игрок впервые (сценарий 30 сек после пробуждения)
Темно → кап-кап → мох под боком → светляк близко (дзынь!) → писк «мама! светится!» → топот → тёплая лапа (Мама): «Тихо-тихо… Ты упал. Ты вписан. Ешь». → свет нарастает (банка). → книга скрипит (Рука записывает). → гул города далеко. Игрок понимает: страшно было 10 секунд, тепло — дальше.
