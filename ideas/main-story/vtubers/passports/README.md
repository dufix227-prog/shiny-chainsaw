# Паспорта витуберш Братишкина

По одной карточке на каждую витубершу (автор: «все», каждая особая). Основа: [образы-канон](../89squad-data/personas-canon-2026-09-08.md) и [внешности](../89squad-data/appearances-2026-09-08.md). **Поля «Реплики-заготовки» пустые — заполняет автор** (правило: реплики реальных людей не сочиняем; игровые персонажи-камео говорят словами автора).

Общая для всех механика подвала Братишкина (канон С4): стримят за долярики; при ветке кражи кот выбирает, какую украсть; побег возможен с витубершей или без. У каждой — своя «фишка» в подвале, свой вкус/страх/секрет (придуманы по их TG/«О канале», правятся автором). Все поля с пометкой «(предложение)» — канон после слова автора.
