# Передача vision-модели — разбор витуберш по снимкам (08.09.2026)

От GLM-5.3-Flash (текстовая модель без зрения). Папка: [89squad-data/](.). Автор просил: описать внешность и характер витуберш, по возможности зайти в их Telegram. Характер и внешность — только из того, что видно/написано самими стримершами; за реальных людей ничего не выдумывать ([правила](../../../main-story/vtubers/plan.md)).

## Что уже сделано текстовой моделью

1. **Маппинг снимков на логины** — [mapping-2026-09-08.md](mapping-2026-09-08.md): все 38 изображений подписаны через OCR; нужно только подтвердить по картинкам (особенно `boopa`-снимок 145531 и `Luriya.png`). **Приоритет по уточнению автора (08.09) — 26 его снимков «Знімок_…»; 12 именованных — старые референсы, сверка только Luriya.png.**
2. **Публичные данные каналов** — [channels-public-data-2026-09-08.md](channels-public-data-2026-09-08.md) + [twitch-snapshot-2026-09-08.json](twitch-snapshot-2026-09-08.json): описания «О канале», подписчики, TG-ссылки (7 найдено).
3. `veoshang` удалён с Twitch к 08.09 — в витуберши игры его, вероятно, не включать; решает автор.

## Что делать vision-модели

### Шаг 1. Подтвердить маппинг
**Приоритет — 26 авторских снимков «Знімок_…»** (по уточнению автора от 08.09 парсить нужно было именно их). Открыть каждый файл из [89squad/](../../lore/cameos/89squad/README.md), сравнить аватар/баннер/имя в кадре с логином из [mapping-2026-09-08.md](mapping-2026-09-08.md). Отметить расхождения. 12 именованных файлов (valiniana.png и др.) — старые одобренные референсы 06.09: их маппинг очевиден из имён файлов, vision-сверка нужна только Luriya.png.

### Шаг 2. Описать внешность каждой витуберши
По аватару, баннеру и кадрам стрима в снимке: раса/вид персонажа (котик, лиса, фея, дракон и т.п.), цвет волос/шерсти, заметные аксессуары, цветовая палитра модели. Формат — 2–4 фактических строки на канал, без оценок и додумок характера. «На снимке не видно» — допустимый ответ.

### Шаг 3. Сверить тон «О канале»
Описания уже собраны дословно. Vision-модель добавляет: если в кадре видны панели с правилами/соцсетями — переписать оттуда ссылки (t.me, boosty, youtube) в [channels-public-data](channels-public-data-2026-09-08.md).

### Шаг 4. Собрать TG-каналы из панелей
У большинства витуберш TG-ссылка лежит в панели «О канале» на Twitch (текстовой модели без браузера она недоступна). Открыть `twitch.tv/<логин>/about` браузером, выписать все ссылки панелей, по каждой t.me зайти и законспектировать публичное описание канала (название, био, тон постов — 1–2 строки). Особо: у `vior_j` ссылка командой «!тг» в чате.

### Шаг 5. Черновики карточек
После шагов 1–4 завести по каждому каналу заметку «внешность (из снимков) + публичный тон (из их же описаний)» и отдать автору на отбор: кто из списка — витуберши игры ([план витуберш](../../../main-story/vtubers/plan.md)). Игровые характеры и реплики пишет автор, не модель.

## Границы

- Снимки — референсы, не материал для релиза; перед выпуском — проверка прав ([камео](../../lore/cameos/plan.md)).
- Не подписывать реальные имена/возрасты; не переносить дословные фразы стримерш в диалоги игры без решения автора.
