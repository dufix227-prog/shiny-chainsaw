Технические решения Hoplite до ответа автора (можно поменять одним решением):

1. Реестр чисел сразу заполнен по уже известным значениям из планов; пустые места помечены `открыто` (вопрос 1 из плана процесса).
2. Таблица готовности живёт в самом [плане исполнения, §18](../execution-2026-09-09.md) и не дублируется здесь — место её постоянного хранения выбирает автор (вопрос 2).
3. Реестр ассетов включает и программно созданные пробы — они помечены `временный`/`техническая проба` (вопрос 3; это согласуется с ПР5).
