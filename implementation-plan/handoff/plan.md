## Последняя просьба и ближайший шаг

**Блокер без внешней клавиатуры закрыт в коде 07.09.2026:** в пробе есть стартовое меню, пауза, настройки качества и штатный выход; добавлены нативные действия Deck. **Текущая задача при продолжении:** пройти уже существующую пробу встроенными органами Deck и записать фактический отзыв. Левый стик/крестовина — ходьба; A — действие/подтвердить; B — назад/закрыть; X — инвентарь; Y — нужды; L1 — отдых; R1 — качество; View — камера; Menu — пауза; R3 — новая попытка. Steam Input с эмуляцией клавиатуры не нужен для базового пути. **Обновления 08.09.2026:** кнопка «Съесть» из окна удалена (еда через Y/ПКМ → «Использовать» и Enter); перестановка предметов как в Minecraft — перенос в пустой и обмен занятых слотов; построена стартовая локация лес (решение автора — кот стартует с леса); физический контроллер Deck отключается в тестах без joypad-сценариев. План исполнения пролога — [game/ПЛАН-ПРОЛОГА.md](../../game/ПЛАН-ПРОЛОГА.md), контекст параллельной работы — [game/CONTEXT.md](../../game/CONTEXT.md).

Минимальная приёмка без внешних устройств: стартовое меню → начать → идти/остановиться → включить нужды и подбор → подобрать пакет → открыть инвентарь → съесть/закрыть → отдохнуть → снять паузу после потери фокуса → сбросить попытку → выйти через меню. Проверить достижимость кнопок и фокус в окне инвентаря; автоматическая эмуляция событий не доказывает настоящую кнопку Deck. Сохранить клавиатурный ввод, масштаб, графику, баланс и однократность подбора. Аппаратную проверку подтверждает только авторский проход на Deck; запросить короткий отзыв, не длинную анкету.

## Что реально существует

- [game/3d-probe/](../../game/3d-probe/README.md): Godot 4.7.2/GDScript, управляемый антропоморфный кот, дорога/берег/дерево/дом, коллизии, две камеры, 720p/1080p/400p. Никаких досок у озера в этой пробе.
- Тестовые **26 м** теперь равны **318,24 единицы мира**; скорость 3,4 ед./с сохранена. Прямой проход F — 93,6 с игрового времени. Ориентир полного пролога — 500 м за полчаса **чистой ходьбы**, прочие занятия сверху; после проверки автор допускает изменить его.
- Локальная карта следует за котом и открывает только посещённое; сохраняет прошлые открытия. Назад метры уменьшаются, вбок не растут. Таймеры с первого движения до первого достижения конца; R сбрасывает попытку.
- Отдельная отключаемая лаборатория еды/выносливости/отдыха. **N/E/Space/P**, профиль в [needs_probe.tres](../../game/3d-probe/data/needs_probe.tres). По умолчанию нужды выключены; числа временные, это не хард. Выключение замораживает значения, не пополняет их. R — лабораторный сброс, не сейв.
- [start.sh](../../start.sh): нативный запуск текущих исходников, выбор точной версии, проверенная загрузка движка и офлайн-кеш без системной установки. Шаблоны экспорта и браузер для него не нужны.

Новая проба подбора по умолчанию выключена: прежняя лаборатория N/E сохранена. При включении E **только подбирает**, еда расходуется через B-окно. Начальные две порции и подобранная используют один запас; переключение режима не возрождает пакет, R начинает новую попытку. Окно приостанавливает движение/нужды/таймеры только лаборатории; потеря фокуса создаёт отдельную P-паузу, которую закрытие окна не снимает.

**Не сделано:** полный маршрут/история пролога, полноценная система лута и инвентаря (слоты/разные предметы/экипировка), НПС/диалоги, бой/мини-игры, сейвы, телефон, полный перебинд, анимация листвы и финальная аудиосистема. В пробе есть временный локально синтезированный эмбиент, ветер, шаги, подбор и еда; это не замена авторской/лицензированной музыки. Нет подтверждённых FPS или совместимости физического Deck.

## Запуск и проверка

На Linux/Deck из скачанной распакованной папки:

```sh
bash ./start.sh
# Подготовка без окна или диагностика логики:
bash ./start.sh --setup-only
bash ./start.sh --headless --quit-after 60
```

ZIP подходит для игры; для разработки и публикации нужен полноценный рабочий Git-репозиторий. Лаунчер не делает `git pull`, не меняет ветку и не обновляет исходники из сети. Для новой версии нужно скачать новый ZIP или обновить свою рабочую копию обычным разрешённым способом.

В Hoplite использовать настроенные setup/Preview-инструменты: `.hoplite/settings.json` → `.hoplite/godot_preview.py`, порт 3000. **Не переносить sandbox-установку браузера на Steam Deck** и не подменять dev-Preview фоновым ручным сервером. После материальной UI-правки проверять настоящую сцену в браузере, не только DOM канваса.

Проверки из корня репозитория (после `bash ./start.sh --setup-only` движок лежит в `~/.cache/10000-metres-probe/godot-4.7.2-linux-x86_64/godot`):

```sh
ENGINE=~/.cache/10000-metres-probe/godot-4.7.2-linux-x86_64/godot
python3 -m unittest discover -s game/tests -p 'test_*.py' -v
# Настоящая чистая установка и офлайн-повтор; требует сети для первого запуска:
python3 game/tests/smoke_start.py
$ENGINE --headless --path game/3d-probe --editor --import --quit
for suite in run rendering needs pacing inventory probe_inventory inventory_proof menu; do
  $ENGINE --headless --path game/3d-probe --fixed-fps 60 --script tests/$suite.gd
done
git diff --check
```

Последние игровые результаты: **167 проверок при 30/60/120 фиксированных FPS** (119 прежних + 48 новых). До добавления подбора без ускорения чистый headless-проход занял 93,581 с по часам; актуальные ускоренные тесты сохраняют 93,600 с игрового времени. С одним привалом и одной порцией — 102,367 с общего игрового времени. В Web заново проверены подход к пакету без телепортации, E-подбор, B/Enter, расход мышью, предел сытости и закрытие окна. Программный рендер **не означает FPS Deck**. Лаунчер: 15 тестов и smoke актуальных исходников с официальным архивом из кеша. Видео не получено из-за зависания инструмента записи; браузер восстановлен, сценарий после этого прошёл без ошибок. Не переписывать числа как результат собственного запуска, пока сам его не повторил.

Подробный порядок полного пролога — [P0–P9](../prologue/plan.md), разделение обязанностей — [архитектура](../prologue/architecture.md).

Сохранять сообщения автора дословно; не менять оригиналы и стабильные ID историй. При смене решения обновлять связанные действующие планы, но не прошлые цитаты. Перед коммитом проверить ссылки, статусы и список файлов. Не включать `.tools/`, `.godot/`, сборки, кеши, персональные логи или вложения. Автор просит коммитить и публиковать текущую ветку; **PR/слияние без отдельной просьбы не создавать**.
