Сейчас в рабочей ветке есть техническая реализация частей пролога, но визуальная версия не принята автором и не считается готовым полным прологом. Дальнейшая переработка начинается с коротких сравнительных проб; большой проход по 500 м до их выбора запрещён. [Рабочий ориентир автора — 500 м примерно на 30 минут чистой ходьбы](../ideas/prologue/pacing/plan.md); НПС и другие занятия добавляют время сверху.

Ближайший шаг — [проверить актуальную пробу на Steam Deck](../game/steam-deck/README.md) через `start.sh`. После отдельного разрешения 07.09.2026 реализованы тестовая еда в мире и B-инвентарь; P-телефон, общий перебинд и другие взаимодействия остаются [в плане](../ideas/common/design/mechanics/interaction/plan.md).

Перенесено из `ideas/implementation/` 07.09.2026. По старым адресам оставлены только ссылки для сохранности исторического журнала; актуальные планы находятся здесь.
